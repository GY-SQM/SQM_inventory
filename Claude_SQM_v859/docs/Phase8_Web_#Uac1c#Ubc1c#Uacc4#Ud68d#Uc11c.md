## 1. 개요

### 목적
광양 창고 PC에서 실행 중인 tkinter SQM 앱을 **그대로 유지**하면서,  
서울 사무실·외부에서 브라우저로 재고 현황을 **실시간 조회**할 수 있는  
웹 조회 화면을 추가한다.

### 핵심 원칙
- tkinter 앱 **대체 아님** — 병행 운영
- 광양 창고 PC에서 NiceGUI 웹서버 **백그라운드 자동 실행**
- 서울·외부에서 브라우저로 **읽기 전용 조회**
- 동일 SQM DB 사용 — **별도 DB 불필요**

## 4. 작업 목록 (우선순위 순)

### Step 1 — tkinter 앱과 자동 연동 (1~2시간)

**목표:** tkinter SQM 앱 시작 시 NiceGUI 서버 자동 실행

**작업 파일:** `run_bootstrap.py`, `sqm_web/main.py`

**구현 내용:**
```python
# run_bootstrap.py에 추가
def start_web_server():
    """백그라운드 스레드로 NiceGUI 서버 자동 시작"""
    import threading
    from sqm_web.main import start_server
    t = threading.Thread(target=start_server, daemon=True)
    t.start()
    logger.info("[Web] http://localhost:8080 에서 웹 서버 시작됨")
```

**설정 추가 (config.py):**
```python
WEB_SERVER_ENABLED = True   # 웹서버 자동 시작 여부
WEB_SERVER_PORT    = 8080   # 포트번호
WEB_SERVER_HOST    = '0.0.0.0'  # 외부 접속 허용
```

### Step 8 — 외부 접속 설정 (30분)

**목표:** 서울에서 광양 PC에 접속

**방법 A — ngrok (추천, 즉시 가능):**
```bash
# 광양 PC에서 실행
ngrok http 8080
# → https://xxxx.ngrok.io 형태의 URL 생성
```

**방법 B — 포트 포워딩:**
- 광양 인터넷 공유기 관리 화면 접속
- 포트 포워딩: 외부 8080 → 광양 PC IP:8080
- 광양 공인 IP로 접속

**방법 C — VPN:**
- 기동님 회사 VPN이 있으면 사내망으로 직접 접속
