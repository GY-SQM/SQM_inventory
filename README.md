## 포함 범위
- Patch A 빠른 점검표
- Patch B 전체 실행 문서
- Patch C 전체 실행 문서
- Agent Team 운영 구조
- TASK / RESULT / VERIFY / DEBUG 템플릿
- BAT / PowerShell 실행 스크립트

## 권장 실행 순서
1. PATCH_A_QUICK_CHECK.md 확인
2. Patch A 10~20분 빠른 확인
3. Batch B Step 01~08 실행
4. Batch B 검증 완료 후 Batch C Step 01~06 실행
5. 각 단계 PASS 후 다음 단계로 이동
