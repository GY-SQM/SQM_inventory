## 사전 준비
================================================================

1. 스마트폰 크롬 브라우저에서:
   http://[서울PC-IP]:5173/mobile  접속

2. 처음 접속 시:
   - "카메라 사용 허용" → 허용
   - "홈 화면에 추가" → SQM 아이콘 생성 (선택)

3. 와이파이 연결 필수 (서울 서버와 같은 네트워크 또는 VPN)

================================================================
## 시나리오 1: 피킹 처리 (RESERVED → PICKED)
================================================================

**상황**: 출고 예약된 톤백을 창고에서 꺼낼 때

### 스마트폰 사용 (BarcodeScanner):
```
1. /scan-mobile 접속
2. 모드: "피킹 처리" 선택 (RESERVED→PICKED)
3. 카메라 시작
4. 톤백 바코드 스캔
5. ✅ "피킹 완료 (PICKED)" 메시지 확인
6. 진동 피드백으로 스캔 성공 확인
```

### Telegram 사용:
```
1. @Claude_kdnbot: /대기
   → 예약(RESERVED) N건 확인
2. 바코드 수동 입력:
   @Claude_kdnbot: /확정 LOT-2026-001
   → 확인 요청
3. /확인
   → ✅ 출고 확정 완료
```

================================================================
## 시나리오 2: 출고 확정 (PICKED → OUTBOUND)
================================================================

**상황**: 피킹 완료된 톤백을 트럭에 실은 후 최종 확정

### 모바일 대시보드 사용:
```
1. /mobile 접속
2. 홈 화면에서 "출고 확정 대기 (PICKED)" 섹션 확인
3. 해당 LOT의 "확정" 버튼 탭
4. 확인 팝업 → "확정" 탭
5. ✅ 토스트 메시지 확인
6. 30초 후 자동 새로고침으로 상태 변경 확인
```

## 트러블슈팅
================================================================

### 카메라가 안 켜질 때
- 크롬 주소창 왼쪽 자물쇠 → 카메라 권한 "허용"으로 변경
- 페이지 새로고침

### 바코드가 안 읽힐 때
- 수동 입력 사용: 입력란에 바코드 번호 직접 입력 → 처리 버튼
- 조명이 충분한 곳에서 재시도

### 네트워크 오류
- 와이파이 연결 확인
- 서버 상태: @Claude_kdnbot /상태 확인

### "LOT 없음" 오류
- lot 번호 오타 확인
- @Claude_kdnbot /lot [번호] 로 LOT 존재 여부 확인
