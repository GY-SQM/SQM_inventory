## 출고 확정 2단계 인증 테스트
================================================================

### 시나리오 1: 정상 확정
```
1. /확정 [PICKED 상태 LOT번호]
   → "⚠️ 출고 확정 확인 요청" 메시지 확인 □
2. /확인 (30초 내)
   → "✅ 출고 확정 완료" 확인 □
```

### 시나리오 2: 시간 초과
```
1. /확정 [LOT번호]
   → 확인 요청 메시지
2. 30초 이상 대기
3. /확인
   → "⏰ 시간 초과 (30초)" 확인 □
```

### 시나리오 3: 취소
```
1. /확정 [LOT번호]
   → 확인 요청 메시지
2. /취소확인
   → "✅ 명령이 취소되었습니다." 확인 □
```
