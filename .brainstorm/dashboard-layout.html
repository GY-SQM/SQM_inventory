SQM 대시보드 레이아웃 선택

Phase A 파일럿 — 3가지 레이아웃 방향 중 하나를 선택하세요 (클릭)

A — 사이드바 + 카드 그리드 선택됨
고전적 ERP 레이아웃. 왼쪽 아이콘 사이드바 + 상단 KPI 카드 4개 + 재고 테이블.
현재 SQM과 가장 유사한 구조. 학습 비용 최소, 전환 리스크 낮음.
B — 상단 탭 + KPI + 와이드 테이블 선택됨
데이터 집중형 레이아웃. 상단 탭 메뉴 + KPI 5개 + 와이드 데이터 테이블.
가장 많은 정보를 한 화면에. 운영 담당자 위주. 마우스 이동 최소.
C — 대시보드 집중형 (카드+차트+알림) 선택됨
경영진·관제용 대시보드. KPI 카드 + 실시간 알림 패널 + 입출고 추이 차트.
한눈에 현황 파악. Figma 기반 디자인 시스템과 가장 잘 맞는 방향.
