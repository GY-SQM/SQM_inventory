## 1. 시작하기

### 1.1 설치
1. `SQM_v864_3_Setup.exe` 를 더블클릭
2. 설치 경로 기본값(`C:\Program Files\SQM\v864.3\`) 그대로 두고 "다음"
3. "바탕화면 아이콘 생성" 체크 후 설치
4. 바탕화면의 **📦 SQM Inventory** 아이콘 더블클릭

### 1.2 첫 실행
처음 실행 시 약 5초 후 검정 배경의 창이 뜹니다. 상단에 메뉴바(파일/입고/출고/재고/보고서/설정·도구/도움말)가 보이면 정상입니다.

### 1.3 로그인
- v864.3 은 로컬 PC 단일 사용자용입니다. 별도 로그인 없음.
- 데이터는 `settings.ini` 에 지정된 SQLite DB 에 저장됩니다.

## 3. 기본 작업 (Top 10)

### 3.1 📄 PDF 스캔 입고
1. **툴바의 📄 PDF 입고** 또는 **입고 > PDF 스캔 입고** 클릭
2. PDF 파일 선택 → 자동 파싱 → 확인 후 저장
3. 상단 Toast "입고 완료" 뜨면 성공

### 3.2 🚀 즉시 출고
1. 툴바의 🚀 즉시 출고 클릭
2. LOT 검색 → 선택 → 수량 입력 → 출고 확정
3. Dashboard 의 "출고 완료" 카드 숫자가 증가합니다

### 3.3 📋 재고 조회
1. 툴바 📋 재고 조회 또는 Ctrl+I
2. 필터: 제품/상태/LOT 번호
3. 결과 테이블 위 [엑셀 내보내기] 버튼으로 XLSX 저장

### 3.4 🔄 반품
1. 툴바 🔄 반품
2. 원 LOT 선택 → 반품 수량 입력 → 사유 기재 → 저장

### 3.5 ✅ 정합성 검사
- 툴바 ✅ 정합성
- 톤백 합계 ↔ 재고 합계 불일치 감지
- 차이 발생 LOT 목록 화면 + 자동 Excel 내보내기 옵션

### 3.6 💾 백업
- 툴바 💾 백업 → 기본 경로 `%APPDATA%\SQM\backups\YYYY-MM-DD.db`
- 일일 1회 이상 권장

### 3.7 📊 Dashboard
- 사이드바 📊 Dashboard (기본 화면)
- 좌: 제품별 재고 요약 | 우: LOT별 기초/입고/출고/기말

### 3.8 📷 Scan
- 사이드바 📷 Scan
- 바코드 리더 연결 시 자동 입력. 없으면 키보드 직접 입력.

### 3.9 🔀 Move (위치 이동)
- 사이드바 🔀 Move
- 원 위치 → 이동 위치 → 대상 LOT 선택 → 확정

### 3.10 📝 Log (활동 로그)
- 사이드바 📝 Log
- 모든 입고·출고·이동·정합성 검사 이력 조회 (최근 100~1000건)

## 4. 돈백/LOT/MT 라디오

화면 우측 상단의 **3종 라디오 버튼**은 수량 표시 단위를 전환합니다.
- **돈백:** 개별 돈백(ton bag) 단위
- **LOT:** LOT 단위
- **MT (기본):** 메트릭 톤 (합계 기준)

선택 즉시 Dashboard/Inventory 테이블이 새 단위로 재계산됩니다.

## 6. ALERTS 패널 (하단 경고)

화면 하단의 빨간색 경고 패널은 **실시간으로 30초마다 갱신** 됩니다.

자주 등장하는 경고:
- **🏷️ 톤백 무결성 이슈 N건** — 합계 불일치. [재고 → 정합성 검사] 로 해소
- **📍 위치 미배정 톤백 N개** — 입고 후 창고 위치 미지정. [재고 → 위치배정] 즉시 처리

## 8. 자주 묻는 질문 (FAQ)

**Q1. 프로그램이 실행이 안 돼요.**
A. `%APPDATA%\SQM\logs\sqm_webview.log` 확인. 일반적으로 포트 8765 충돌 → 재부팅 후 재시도.

**Q2. 데이터가 안 보여요.**
A. 메뉴바 🔁 새로고침 클릭. 그래도 안 되면 [설정 → 환경 설정] 에서 DB 경로 확인.

**Q3. "준비 중" 메시지가 뜹니다.**
A. 해당 기능은 Tier 3 이후 고도화 예정. 현재는 UI 만 활성화되고 실제 동작은 추후 버전에서.

**Q4. 엑셀로 내보내려면?**
A. [보고서 → Excel 내보내기] 또는 각 페이지의 [내보내기] 버튼.

**Q5. 바코드 리더가 인식 안 돼요.**
A. USB 연결 확인 → 키보드 에뮬레이션 모드(HID) 설정 → Scan 페이지 입력창에 포커스 후 스캔.
