## 1. v864.2와 동일한 것들

### 1.3 핵심 업무 흐름 (변경 없음)

**입고 프로세스:**
```
OneStop 입고 클릭
  → BL/PL/INV/DO PDF 업로드
  → 자동 파싱 + 크로스체크
  → 프리뷰 확인 (편집 가능)
  → 저장 버튼 → DB 기록
```

**출고 프로세스:**
```
할당 페이지에서 할당 파일 업로드
  → 예약(RESERVE) → 피킹(PICK) → 출고(OUTBOUND)
  → 바코드 스캔 확인 (선택)
  → 증빙 서류 자동 생성
```

## 2. 새로 추가된 기능

### 2.1 전역 검색 (Global Search)

- **위치:** 화면 상단 검색창 (🔍)
- **기능:** LOT 번호, 제품명, BL번호, 컨테이너 번호를 동시에 검색
- **단축키:** `Ctrl+F`
- **사용법:**
  1. 상단 검색창에 검색어 입력
  2. Enter 또는 검색 버튼 클릭
  3. 결과를 클릭하면 해당 LOT로 바로 이동

**v864.2와 차이:** v864.2는 각 탭에서 개별 검색만 가능했으나, v864.3는 전체 데이터를 한 번에 검색합니다.

### 2.2 AI 채팅 어시스턴트

- **위치:** 우하단 💬 버튼 또는 메뉴 → 도구 → AI 채팅
- **기능:** 재고 현황 질의, 데이터 분석 요청
- **예시 질문:**
  - "현재 AVAILABLE 상태 LOT 목록 알려줘"
  - "지난 한 달 출고량 요약해줘"
  - "무결성 오류가 있는 LOT 있어?"
- **설정:** 메뉴 → 설정 → AI 탭에서 Gemini API 키 입력

**v864.2와 차이:** 신규 기능.

### 2.3 Preview-Edit-Save (프리뷰 편집 저장)

입고 파싱 후 DB 저장 전에 데이터를 직접 수정할 수 있습니다.

**흐름:**
1. PDF 업로드 → 파싱 결과 프리뷰 표시
2. 셀을 더블클릭하여 값 수정
3. 확인 버튼으로 DB 저장

**v864.2와 차이:** v864.2는 파싱 후 즉시 저장되었으나, v864.3는 검토/수정 단계가 추가됩니다.

### 2.4 2단 계층 표 (LOT → 톤백 펼침)

재고/할당/피킹/출고 페이지에서 LOT 행을 클릭하면 하단에 톤백 목록이 펼쳐집니다.

**사용법:**
1. 재고 탭에서 LOT 행 클릭
2. 행 아래에 해당 LOT의 톤백 목록이 표시됨
3. 다시 클릭하면 접힘

**v864.2와 차이:** v864.2는 별도 팝업 창이었으나, v864.3는 인라인으로 펼쳐집니다.

### 2.5 다크/라이트 테마 전환

- **위치:** 우상단 🌙/☀️ 버튼
- **기본값:** 다크 테마 (v864.2와 동일)
- **저장:** 선택한 테마는 자동으로 기억됩니다

## 4. 트러블슈팅

### 4.1 프로그램이 시작되지 않는 경우

**증상:** EXE 클릭 후 아무 반응 없음  
**원인 1:** 안티바이러스가 차단  
**해결:** Windows Defender / V3 등에서 `SQM_v864_3.exe` 예외 처리

**원인 2:** 데이터베이스 파일 없음  
**해결:** `data/db/sqm_inventory.db` 파일이 있는지 확인. 없으면 빈 DB 자동 생성됨.

**원인 3:** 포트 8765 사용 중  
**해결:** 작업 관리자에서 포트 8765를 사용하는 다른 프로그램 종료 후 재시작

### 4.2 PDF 업로드 후 파싱 결과가 없는 경우

**증상:** PDF 업로드했는데 프리뷰 표가 비어 있음  
**원인:** 지원하지 않는 PDF 형식 또는 스캔본 PDF  
**해결:**
1. PDF가 텍스트 레이어가 있는지 확인 (Adobe Acrobat에서 텍스트 복사 가능한지 테스트)
2. 스캔본이라면 OCR 처리 후 재업로드
3. 지원 형식: Maersk BL, Packing List (표준 양식), FA/Invoice

### 4.3 화면이 하얗게 비어 있는 경우

**증상:** 탭 전환 후 내용이 표시되지 않음  
**해결:**
1. `Ctrl+R`로 새로고침
2. 그래도 안 되면 사이드바의 다른 탭 클릭 후 돌아오기
3. 로그 파일 확인: `logs/sqm_debug.log`

### 4.4 속도가 느린 경우

**증상:** 재고 탭 로딩이 3초 이상 걸림  
**원인:** LOT 수가 많을 경우 (1000개 이상)  
**해결:**
1. 메뉴 → 파일 → DB 최적화 실행
2. 검색/필터를 활용하여 조회 범위 축소
3. `설정 → 일반 → 페이지당 행 수` 축소 (기본 50)

### 4.5 v864.2 데이터를 v864.3으로 가져오는 법

v864.2와 v864.3은 **동일한 SQLite DB 형식**을 사용합니다.

**방법:**
1. v864.2 설치 폴더의 `data/db/sqm_inventory.db` 복사
2. v864.3 설치 폴더의 `data/db/` 에 덮어쓰기
3. v864.3 실행

> ⚠️ 덮어쓰기 전에 반드시 백업하세요.

### 4.6 로그 위치

| 로그 파일 | 내용 |
|-----------|------|
| `logs/sqm_debug.log` | 전체 디버그 로그 |
| `logs/sqm_error.log` | 에러만 필터 |
| `data/proof_docs/` | 출고 증빙 서류 (90일 보관) |
| `backup/` | 자동 백업 파일 |

## 5. 시작하는 법

### 5.1 EXE 실행 (권장)

1. `dist/SQM_v864_3.exe` 더블클릭
2. Windows 보안 경고 → "추가 정보" → "실행"
3. 약 5~10초 후 메인 화면 표시

### 5.2 개발 모드 실행 (고급)

```bash
# 가상환경 활성화 (필요 시)
cd D:\program\SQM_inventory\Claude_SQM_v864_3

# 서버 + PyWebView 실행
python main_webview.py

# 또는 서버만 실행 (브라우저로 접속)
python -m uvicorn backend.api:app --host 127.0.0.1 --port 8765
# 브라우저에서: http://127.0.0.1:8765
```

### 5.3 초기 설정

1. **Gemini API 키 (선택):** 메뉴 → 설정 → AI 탭 → API 키 입력
2. **이메일 설정 (선택):** 메뉴 → 설정 → 이메일 탭 → SMTP 설정
3. **자동 백업:** 메뉴 → 설정 → 백업 탭 → 주기 설정
