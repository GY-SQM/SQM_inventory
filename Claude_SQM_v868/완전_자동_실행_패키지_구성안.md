# SQM 완전 자동 실행 패키지 구성안
생성일: 2026-04-04 00:20

## 목적
MASTER + BAT + PowerShell + Telegram Bridge + .env 를 하나의 실행 흐름으로 묶는다.

---

## 1. 포함 파일
```text
docs/MASTER.md
scripts/claude_telegram_bridge_final.py
run_claude_sqm_precise.bat
run_claude_sqm_precise.ps1
.env
docs/run_log.txt
docs/TEST_REPORT.md
logs/telegram_bridge.log
```

---

## 2. 권장 실행 순서
1. `.env` 준비
2. MASTER.md 최신본 반영
3. BAT 또는 PS1 실행
4. 사전 테스트 자동 수행
5. bridge가 Claude 실행
6. 멈춤 발생 시 Telegram 알림
7. Telegram 답장으로 재개
8. 완료/실패 로그 기록

---

## 3. .env 기본 항목
```env
BOT_TOKEN=123456789:ABCdefGhijklmnopqrstuvwxyz
CHAT_ID=538125119
ADMIN_TOKEN=change-admin-token
IDLE_TIMEOUT=30
RECENT_CHARS=500
POLL_INTERVAL=2
```

> 보안상 실제 운영 시에는 토큰을 외부에 노출하지 말고, 필요 시 재발급을 고려한다.

---

## 4. BAT / PS1가 반드시 할 일
- backend tests
- frontend tests
- frontend build
- docs/logs 폴더 점검
- MASTER.md 존재 확인
- bridge 파일 존재 확인
- 실패 시 즉시 종료
- 성공/실패 시 run_log.txt 기록

---

## 5. Telegram Bridge가 반드시 할 일
- 질문형 멈춤 감지
- 선택형 1/2 또는 1/2/3 감지
- 다음 단계 대기형 감지
- idle timeout 감지
- 최근 출력과 함께 텔레그램 전송
- 텔레그램 응답(stdin) 주입
- 종료 코드/예외 로그 기록

---

## 6. Claude가 MASTER 기준으로 해야 할 일
- Recon Phase 먼저 수행
- 메뉴바 구현
- 모달 구현
- 쓰기 API 구현
- 테스트 게이트 통과 후 단계 진행
- run_log / TEST_REPORT 갱신
