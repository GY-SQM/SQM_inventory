# SQM v5.0.2 릴리즈 노트

**📅 릴리즈**: 2026-02-11  
**🎯 버전**: v5.0.1 → v5.0.2  
**⭐ 유형**: 사용성 개선 (7개 항목)

---

## 🎯 v5.0.2 개선사항 (7개)

### 1️⃣ Allocation Table 출고 미리보기 (신규!)

**문제**: 출고 실행 전 결과를 확인할 수 없음

**개선**:
```
Allocation Table 파일 선택
    ↓
📊 출고 전 통계 표시
    - 총 재고: 100,020 kg (20개 LOT)
    - 가용: 100,020 kg
    - 출고 예정: 0 kg
    ↓
📋 출고 메시지 표시
    "날짜: 2026-02-11
     품목: LITHIUM CARBONATE
     톤백: 10개
     샘플: 5개
     출고처: [고객명]"
    ↓
📊 출고 후 예상 통계 표시
    - 총 재고: 100,020 kg (20개 LOT)
    - 가용: 95,000 kg
    - 출고 완료: 5,020 kg
    ↓
❓ 사용자 확인
    "출고를 실행하시겠습니까?"
    [예] [아니오]
```

**효과**: 
- ✅ 실수 방지
- ✅ 출고 전 검증
- ✅ 명확한 정보 제공

---

### 2️⃣ Excel 컬럼 개수 확인 및 수정

**문제**: Excel 내보내기 시 컬럼이 18개가 아님

**확인 필요**: 실제 출력되는 컬럼 개수

**목표**: 
```
재고 현황 Excel: 18~20개 전체 컬럼 출력
LOT_NO, SAP_NO, BL_NO, PRODUCT, ARRIVAL,
TOTAL(KG), AVAILABLE(KG), BAGS, STATUS,
CONTAINER, VESSEL, WAREHOUSE, LOCATION,
FREE_TIME, CUSTOMS, CREATED_AT, UPDATED_AT, REMARKS
(+ 추가 컬럼 필요 시)
```

---

### 3️⃣ 모든 테이블에 합계 표시

**개선**: 모든 표 하단에 합계 행 추가

**적용 위치**:
- ✅ 재고리스트: LOT 개수, 총 중량
- ✅ 톤백리스트: 톤백 개수, 총 중량
- ✅ 통계: 각 항목별 합계
- ✅ 출고 내역: 출고 개수, 총 중량
- ✅ 입고 내역: 입고 개수, 총 중량

**표시 형식**:
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
합계 | 20개 LOT | 100,020 kg | 200개
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

---

### 4️⃣ 메뉴 버튼 색상 문제 수정

**문제**: 메뉴 클릭 시 검게 변하고 복구 안 됨

**해결**:
```python
# toolbar_mixin.py 또는 메뉴 핸들러
def on_menu_click(self, button):
    # 작업 수행
    self._execute_action()
    
    # v5.0.2: 버튼 상태 복구
    button.state(['!pressed', '!active'])
    self.root.update_idletasks()
```

---

### 5️⃣ Excel 불러오기 메뉴 간소화

**Before**: 너무 많은 메뉴
```
📁 재고현황 Excel
📁 상세내역 Excel
📁 통관요청 양식
📁 루비리 양식
📁 톤백 현황
📁 통합 현황
```

**After**: 핵심 2개만
```
📁 재고리스트 Excel 불러오기
📁 톤백리스트 Excel 불러오기
```

**이유**: 
- 사용자 혼란 방지
- 핵심 기능 집중
- UI 단순화

---

### 6️⃣ 대시보드 입출고 표시 확인

**확인 사항**:
```
대시보드 화면:
- 총 재고: 100,020 kg
- 총 LOT: 20개
- 금일 입고: 0 kg  ← 확인 필요
- 금일 출고: 0 kg  ← 확인 필요
- 톤백: 220개
```

**수정 필요 시**:
- 금일 입고/출고 제대로 계산되는지 확인
- created_at 날짜 기준 필터링 검증

---

### 7️⃣ Allocation Table 출고 로직 개선

**전체 흐름**:
```
1. 파일 선택
2. Excel 파싱
3. 출고 전 통계 계산
4. 미리보기 표시
5. 출고 메시지 생성
6. 출고 후 통계 계산
7. 사용자 확인 요청
8. [예] 클릭 시 → 실제 출고 실행
9. [아니오] 클릭 시 → 취소
```
