# 컬럼 토글 + 표시 모드 기능 완료!

**버전**: v5.0.2  
**날짜**: 2026-02-11

---

## ✅ 추가된 기능 (2개)

### 1️⃣ 표시 컬럼 (체크박스)
컬럼을 체크/해제하여 표시/숨김 전환!

**재고 리스트**:
```
표시 컬럼: ☑ SAP NO  ☑ BL NO  ☑ CONTAINER  ☑ SHIP DATE  ☑ FREE TIME  ☑ CUSTOMS
```

**톤백 리스트**:
```
표시 컬럼: ☑ SAP NO  ☑ BL NO  ☑ CONTAINER  ☑ LOCATION  ☑ WEIGHT  ☑ STATUS
```

### 2️⃣ 표시 모드 (라디오 버튼)
행 높이를 선택하여 가독성 조절!

```
표시 모드: ◯ 컬럼  ◯ 본문  ◯ 날짜
```

**모드별 행 높이**:
- 컬럼 (compact): 24px - 많은 데이터 표시
- 본문 (normal): 28px - 기본 (현재)
- 날짜 (comfortable): 32px - 여유있게

## 🎯 사용 방법

### 1. 컬럼 표시/숨김
```
재고 리스트 탭 상단
→ "표시 컬럼" 영역 확인
→ SAP NO 체크 해제
→ SAP NO 컬럼이 테이블에서 사라짐!
```

### 2. 표시 모드 변경
```
오른쪽 "표시 모드" 영역
→ "날짜" 선택
→ 행 높이가 32px로 증가!
→ 데이터가 더 여유있게 표시됨
```
