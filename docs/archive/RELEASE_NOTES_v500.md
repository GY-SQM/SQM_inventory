# SQM v5.0.0 릴리즈 노트 (Major Update)

**📅 릴리즈**: 2026-02-11  
**🎯 버전**: v4.19.1 → v5.0.0  
**⭐ 메이저 업데이트**: 완전 통일 버전

---

## 🎊 v5.0.0 - 완전 통일 버전

### **"모든 UI가 하나로 통일된 전문가급 시스템"**

---

## 🌟 주요 특징

### ✨ 완벽한 통일성
- **모든 표** → 동일한 스타일
- **모든 헤더** → 첫글자 대문자 통일
- **모든 창** → 그리드 + 정렬 + 줄무늬
- **모든 파일** → v5.0.0 표시

---

## 🎯 v5.0.0에서 달성한 것

### 1️⃣ 자동 스타일 적용 시스템
**신규 기능**: 모든 Treeview에 자동으로 스타일 적용!

```python
# v5.0.0: 자동 탐색 + 자동 적용
apply_styles_to_all_trees(root)

# 모든 표에 자동으로:
✅ 그리드 라인
✅ 가운데 정렬  
✅ 줄무늬 배경
✅ 진한 헤더
```

**효과**:
- ✅ 재고리스트 - 통일됨
- ✅ 톤백리스트 - 통일됨
- ✅ 통계 - 통일됨
- ✅ 대시보드 - 통일됨
- ✅ 출고 - 통일됨
- ✅ 모든 팝업 - 통일됨

---

### 2️⃣ 헤더 대문자 통일
**개선**: 모든 컬럼 헤더 첫글자 대문자

```
Before (v4.x):
id, lot_no, sap_no, product, status, uid

After (v5.0.0):
ID, Lot_No, SAP_No, Product, Status, UID
```

**적용 위치**:
- ✅ 재고리스트
- ✅ 톤백리스트
- ✅ 출고 내역
- ✅ 입고 내역
- ✅ 통계 테이블
- ✅ Excel 내보내기

---

### 3️⃣ 진한 헤더 배경
**Before (v4.x)**:
- 헤더: 기본 회색
- 글자: 검은색

**After (v5.0.0)**:
- 헤더: 진한 회색 (#34495E)
- 글자: 흰색 + 굵게
- Hover: 더 진한 회색 (#2C3E50)

---

### 4️⃣ 줄무늬 배경 자동 적용
**v5.0.0**: 모든 표에 자동으로 줄무늬!

```
홀수 행: 연한 회색 (#F8F9FA)
짝수 행: 흰색 (#FFFFFF)
```

**적용 범위**:
- ✅ 기존 데이터
- ✅ 새로 추가되는 데이터
- ✅ 모든 팝업 창
- ✅ 모든 탭

---

### 5️⃣ 통일된 행 높이
**v5.0.0**: 모든 표 행 높이 통일

```
Before: 25~28px (불균일)
After: 30px (통일)
```

**효과**: 모든 화면에서 일관된 느낌!

### 🎯 Major Update 이유

**v4.x → v5.0.0**은 단순한 버전 업이 아닙니다:

1. **완전한 통일** - 모든 UI 100% 통일
