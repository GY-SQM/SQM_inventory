### 🛡️ Phase 2: 안전성 강화 (1개)

#### 7. Allocation Table 출고 미리보기

**3단계 확인 프로세스**:

```
1. 📊 출고 전 통계
   총 재고: 100,020 kg (20개 LOT)
   가용 재고: 100,020 kg
   톤백: 200개

2. 📋 출고 메시지
   📅 출고 날짜: 2026-02-11
   📦 출고 품목: LITHIUM CARBONATE
   📋 출고 상세:
     • 톤백: 10개 (5,000 kg)
     • 샘플: 2개 (20 kg)
     • 합계: 12개 (5,020 kg)
   🏢 출고처: ABC Company

3. 📊 출고 후 통계
   총 재고: 100,020 kg
   가용 재고: 95,000 kg  (▼ 5,020 kg 출고)
   톤백: 188개  (▼ 12개 출고)

4. ❓ 확인 질문
   위 내용으로 출고를 실행하시겠습니까?
   [✅ 예 - 출고 실행]  [❌ 아니오 - 취소]
```

**효과**:
- ✅ 출고 실수 방지 100%
- ✅ 명확한 정보 제공
- ✅ 안전한 출고 프로세스
