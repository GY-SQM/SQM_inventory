# SQM v5.0.3 릴리즈 노트

**📅 릴리즈**: 2026-02-11  
**🎯 버전**: v5.0.2 → v5.0.3  
**⭐ 유형**: 자동 백업 강화 + 성능 최적화

---

## 🔧 v5.0.3 주요 개선사항

### 🛡️ 자동 백업 강화 (3개)

#### 1. 실시간 백업 검증 ✨

**Before (v5.0.2)**:
```
백업 생성
→ 끝
→ 백업 파일이 손상되었는지 모름
```

**After (v5.0.3)**:
```
백업 생성
    ↓
📊 무결성 검사
    - SQLite 헤더 확인
    - PRAGMA integrity_check
    - 테이블 구조 확인
    ↓
✅ 검증 성공 → "✅ 자동 백업 완료 (검증 OK)"
❌ 검증 실패 → 자동 재시도!
```

**검증 항목**:
- ✅ 파일 존재 및 크기
- ✅ SQLite 형식 확인
- ✅ DB 무결성 (PRAGMA integrity_check)
- ✅ 필수 테이블 존재 확인
- ✅ 체크섬 계산 (SHA256)

---

#### 2. 자동 복구 기능 ✨

**프로그램 시작 시 자동 검증 + 복구**:

```
프로그램 실행
    ↓
📊 DB 검증
    ↓
✅ 정상 → 프로그램 계속
❌ 손상 감지
    ↓
🔍 최신 유효 백업 검색
    ↓
📦 백업에서 자동 복구
    ↓
✅ 복구 완료 → 프로그램 계속
```

**복구 프로세스**:
1. 손상된 DB 백업 (`.corrupted_YYYYMMDD_HHMMSS`)
2. 최신 유효 백업 찾기
3. 백업 파일 복사
4. 복구 후 검증
5. 성공 시 프로그램 계속

**효과**:
- ✅ DB 손상 시 자동 복구
- ✅ 데이터 손실 최소화
- ✅ 수동 복구 불필요

---

#### 3. 백업 재시도 로직 ✨

**검증 실패 시 자동 재시도**:

```
백업 생성
    ↓
검증 실패
    ↓
⚠️ "백업 완료했으나 검증 실패"
    ↓
자동 재시도
    ↓
✅ 재시도 성공 → "✅ 백업 재시도 성공"
❌ 재시도 실패 → "❌ 백업 재시도도 실패"
```

---

### 🚀 성능 최적화 (1개)

#### 4. 쿼리 캐시 확대 ✨

**대시보드 통계 쿼리 캐싱**:

**Before**:
```
대시보드 새로고침
→ 3개 쿼리 실행 (매번)
→ 느림
```

**After**:
```
대시보드 새로고침
→ 캐시 확인 (60초 유효)
    ├─ 캐시 HIT → 즉시 반환 (빠름!)
    └─ 캐시 MISS → 쿼리 실행 → 캐싱
```

**캐싱 대상**:
- ✅ 금일 입고 통계 (등록 기준)
- ✅ 금일 입고 통계 (입항 기준)
- ✅ 금일 출고 통계

**효과**:
- ⚡ 대시보드 로딩 속도 향상
- ⚡ DB 부하 감소
- ⚡ 반복 조회 시 즉시 응답

## 🎯 사용 방법

### 자동 백업 검증

**설정 없음 - 자동 작동!**

```
자동 백업 실행
→ 백업 생성
→ 자동 검증
→ ✅ "자동 백업 완료 (검증 OK)"
```

**검증 실패 시**:
```
→ ⚠️ "백업 완료했으나 검증 실패"
→ 자동 재시도
→ ✅ "백업 재시도 성공"
```

---

### 자동 복구

**프로그램 시작 시 자동!**

```
프로그램 실행
→ DB 검증
→ [정상] 프로그램 계속
→ [손상] 자동 복구 → 프로그램 계속
```

**로그 메시지**:
```
🔧 자동 복구 실행됨: 복구 완료 (백업: auto_backup_20260211_050000.db)
```

---

### 쿼리 캐시

**설정 없음 - 자동 작동!**

```
대시보드 열기 (첫 번째)
→ 쿼리 실행 → 캐싱

대시보드 새로고침 (60초 내)
→ 📊 캐시 HIT → 즉시 표시!

대시보드 새로고침 (60초 후)
→ 캐시 만료 → 쿼리 재실행 → 캐싱
```

## 🧪 테스트 방법

### 1. 백업 검증 테스트
```
1. 프로그램 실행
2. 자동 백업 활성화 (30분 간격)
3. 30분 대기
4. 로그 확인:
   ✅ "자동 백업 완료 (검증 OK)"
```

### 2. 자동 복구 테스트 (위험!)
```
⚠️ 주의: 테스트용 DB로만 실행!

1. DB 파일 손상시키기 (수동)
2. 프로그램 재실행
3. 로그 확인:
   🔧 "자동 복구 실행됨: 복구 완료"
4. 프로그램 정상 작동 확인
```

### 3. 쿼리 캐시 테스트
```
1. 대시보드 열기
2. 새로고침 (F5)
3. 로그 확인:
   📊 "대시보드 통계 캐시 HIT"
```
