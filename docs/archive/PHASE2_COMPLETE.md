## ✅ 완료된 작업

### Allocation Table 미리보기 다이얼로그 (신규!)

**전체 흐름**:
```
1. 파일 선택 (Excel)
   ↓
2. 파일 파싱 (AllocationParser)
   ↓
3. 미리보기 다이얼로그 표시
   ├─ 출고 전 통계
   ├─ 출고 메시지
   ├─ 출고 후 통계
   └─ 상세 내역 (테이블)
   ↓
4. 사용자 확인
   ├─ [예] → 출고 실행
   └─ [아니오] → 취소
```

## 📋 미리보기 화면 구성

### 1️⃣ 출고 전 통계
```

━━━━━━━━━━━━━━━━━━━━━━
총 재고: 100,020 kg (20개 LOT)
가용 재고: 100,020 kg
톤백: 200개
```

### 2️⃣ 출고 메시지
```
📋 출고 계획
━━━━━━━━━━━━━━━━━━━━━━
📅 출고 날짜: 2026-02-11
📦 출고 품목: LITHIUM CARBONATE

📋 출고 상세:
  • 톤백: 10개 (5,000 kg)
  • 샘플: 2개 (20 kg)
  • 합계: 12개 (5,020 kg)

🏢 출고처: ABC Company
```

### 3️⃣ 출고 후 통계
```
📊 출고 후 예상 통계

가용 재고: 95,000 kg  (▼ 5,020 kg 출고)
```

## 🎯 사용 방법

### 1. Allocation Table 파일 준비
```excel
LOT_NO       | PRODUCT           | QTY(MT) | SUB_LT | SOLD_TO
1125072729   | LITHIUM CARBONATE | 2.5     | 5      | ABC Co.
1125072730   | LITHIUM CARBONATE | 2.5     | 5      | ABC Co.
```

### 2. 메뉴 선택
```
출고 → 📋 출고 Allocation Table
```

### 3. 파일 선택
```
파일 선택 다이얼로그
→ Excel 파일 선택
```

### 4. 미리보기 확인
```
📊 출고 전 통계 확인
📋 출고 메시지 확인
📊 출고 후 통계 확인
📋 상세 내역 확인
```

### 5. 실행 또는 취소
```
[✅ 예] 클릭 → 출고 실행
[❌ 아니오] 클릭 → 취소
```

## 🔍 주요 기능

### 출고 전 통계
- ✅ 현재 총 재고 (kg, LOT 수)
- ✅ 가용 재고
- ✅ 톤백 개수

### 출고 메시지
- ✅ 출고 날짜 (자동 오늘 날짜)
- ✅ 출고 품목
- ✅ 톤백/샘플 개수 및 중량
- ✅ 출고처

### 출고 후 통계
- ✅ 출고 후 가용 재고 (감소량 표시)
- ✅ 출고 후 톤백 개수 (감소량 표시)

### 상세 내역
- ✅ LOT별 출고 정보
- ✅ 스크롤 가능 테이블
- ✅ 중량/톤백 수 표시
