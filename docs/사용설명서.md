# SQM 재고관리 — 직원용 사용설명서

> 대상: 광양 창고 직원·신규 입사자
> 만든이: 남기동 대표 / 시스템 자동화 본부
> 최종 갱신: 2026-07-21
> 버전: v8.8.5
>
> 이 문서는 **컴퓨터 기본만 아는 직원**도 처음부터 따라 할 수 있게 만들었어요.
> 모르는 단어가 나오면 옆에 한 줄 설명을 붙였어요. 천천히 읽어 주세요.

---

## 1. 이 프로그램이 하는 일 (한 줄씩)

1. **입고**된 화물의 **LOT**(한 번에 들어온 묶음) 정보를 PDF/Excel에서 자동으로 읽어 저장해요.
2. **창고 위치**에 어디에 둘지 배정해요.
3. **출고**할 때 바코드/PDF로 빠르게 찾아서 내보내요.
4. **반품**이 들어오면 다시 재고로 돌려놓거나 따로 표시해요.
5. 매일 아침 **전일 재고 / 오늘 입고 / 오늘 출고** 숫자를 한눈에 보여줘요.

---

## 2. 시작하기

### 처음 한 번만: 바탕화면에 아이콘 만들기

1. `D:\program\sqm\SQM_inventory` 폴더를 열어 주세요.
2. `SQM.vbs` 파일을 찾아 주세요.
3. `SQM.vbs` 를 **마우스 오른쪽 클릭** → **"보내기"** → **"바탕화면 (바로가기 만들기)"** 를 눌러 주세요.
4. 바탕화면에 생긴 바로가기의 이름을 **"SQM 재고관리"** 로 바꿔 주세요.

### 매일 아침: 프로그램 켜기

1. 바탕화면의 **"SQM 재고관리"** 아이콘을 **더블클릭**해 주세요.
2. 3~5초 정도 기다리면 회색 창이 떠요.
3. 그 다음 회색 창 안에 **웹 페이지**(대시보드)가 뜬 다음, 사이드바(왼쪽 메뉴)가 보이면 준비 끝이에요.
4. 안 뜨면? → "자주 나는 오류 Q&A" 의 **Q1** 을 보세요.

### 매일 저녁: 프로그램 끄기

1. 회색 창 오른쪽 위의 **X 버튼**을 눌러 주세요.
2. "정말 종료하시겠습니까?" 같은 확인이 뜨면 **확인** 눌러 주세요.
3. 그 다음 안 꺼지면 작업 표시줄(아래 시계 옆)에서 SQM 아이콘을 **오른쪽 클릭** → **"창 닫기"** 를 눌러 주세요.

---

## 3. 화면별 사용법

### 화면 0. 대시보드 (가장 먼저 보이는 화면)

- **역할**: 오늘 숫자 한눈에 보기. 작업 시작 전에 먼저 보세요.
- 위에 큰 카드 5개가 있어요 (왼쪽부터):
  1. **전일 재고** — 어제 하루가 끝날 때 남아있던 양
  2. **오늘 입고** — 오늘 들어온 양
  3. **오늘 SOLD** — 오늘 팔려서 나간 양 (= 출고)
  4. **현재 재고** — 지금 이 순간 창고에 있는 양
  5. **미배정 톤백** — 들어왔는데 자리를 안 잡아준 것 (이게 0이 되게 해주세요)

---

### 화면 1. Inventory > Pending (대기 중)

- **역할**: 입고 예정 / 입고 처리 전 상태의 LOT 목록이에요.
- **자주 하는 일**: 새 입고 처리 시작하기
- **순서**:
  1. 좌측 메뉴에서 **Inventory** 를 클릭해 펼치세요.
  2. 그 아래 **⏳ Pending** 을 클릭하세요.
  3. 목록에서 처리할 LOT 행을 클릭하면 위쪽에 **PDF 보기** / **상태 변경** 버튼이 활성화돼요.
  4. **상태 변경** 버튼을 누르면 **Available**(사용 가능)로 바뀌어요. (PDF/Excel 자동 인식은 시스템이 해요.)
- **주의**: `Pending` 이 너무 많으면 **미배정 톤백** 카드도 늘어나요. 매일 0에 가깝게 정리해 주세요.

---

### 화면 2. Inventory > Available (사용 가능)

- **역할**: 현재 팔 수 있는 / 출고 가능한 LOT 목록이에요.
- **자주 하는 일**: 출고할 LOT 찾기, LOT 검색
- **순서 (검색)**:
  1. 우측 상단 **검색창** 에 LOT 번호 일부 (예: `ABC-001`) 입력
  2. 아래 목록이 자동으로 좁혀져요.
  3. **Enter** 키를 누르면 상세 화면이 떠요.
- **순서 (출고 시작)**:
  1. 출고할 LOT 행을 클릭해 선택해 주세요.
  2. 상단 **"출고 시작"** 버튼을 누르세요.
  3. 자동으로 **Picked**(피킹 중) 화면으로 이동해요.

---

### 화면 3. Inventory > Allocation (배정)

- **역할**: 창고 안의 **위치**(A-1-3 같은 칸)에 LOT를 배정하는 화면이에요.
- **자주 하는 일**: 새 LOT 입고 시 자리 잡아주기
- **순서**:
  1. 목록에서 LOT 행을 클릭해 선택해 주세요.
  2. 상단 **"위치 배정"** 버튼을 눌러 주세요.
  3. 빈 자리 목록이 보여요. **빈 칸** (회색으로 표시) 을 클릭하면 배정 완료.
  4. **"저장"** 버튼을 꼭 눌러 주세요. 안 누르면 사라져요.

---

### 화면 4. Inventory > Picked (피킹 중)

- **역할**: 출고 진행 중인 LOT 목록이에요. 바코드 스캔으로 검증해요.
- **자주 하는 일**: 바코드 스캔 → 출고 확정
- **순서**:
  1. 우측 상단 **스캔 시작** 버튼을 눌러 주세요.
  2. 화면이 **Scan** 메뉴로 자동 이동해요.
  3. 핸드스캐너(바코드 총)로 LOT 바코드를 쏴 주세요.
  4. 인식되면 초록색으로 표시되고 다음 LOT로 넘어가요.
  5. 모두 인식되면 자동으로 **Sold**(출고 완료)로 이동해요.
- **주의**: 한 번에 한 LOT만 스캔해 주세요. 한꺼번에 여러 개 스캔하면 잘못 매칭될 수 있어요.

---

### 화면 5. Sold (출고 완료)

- **역할**: 오늘/과거 출고가 끝난 LOT 목록이에요. 회계/통관 자료로 사용돼요.
- **자주 하는 일**: 출고 내역 Excel로 내보내기
- **순서**:
  1. 상단 **날짜 입력** 칸에 시작일/종료일 입력 (예: 2026-07-01 ~ 2026-07-21).
  2. **"Excel 내보내기"** 버튼 클릭.
  3. 저장할 위치 선택 → 파일 이름 입력 → **저장**.
  4. 파일이 열리면 화면이 **Sales Order 내보내기** 같은 이름으로 떠요. 그게 정상이에요.

---

### 화면 6. Return (반품)

- **역할**: 고객이 돌려보낸 LOT를 다시 받는 화면이에요.
- **자주 하는 일**: 반품 등록, 가용재고 복원
- **순서**:
  1. 상단 **"반품 등록"** 버튼 클릭.
  2. 원래 LOT 번호 입력 → **찾기**.
  3. 반품 사유 드롭다운 선택 (파손 / 오배송 / 단순 변심 등).
  4. **"등록"** 클릭. 반품 LOT 가 Pending 상태로 추가돼요.
  5. 검수 후 **"Available로 복원"** 버튼을 눌러 다시 재고로 넣어 주세요.

---

### 화면 7. Move (이동)

- **역할**: 창고 안 LOT 위치를 옮길 때 사용해요.
- **순서**:
  1. 옮길 LOT 행 클릭.
  2. **"위치 이동"** 버튼 클릭.
  3. 새 위치 입력 (예: `B-2-5`).
  4. **"저장"** 클릭.

---

### 화면 8. Scan (스캔)

- **역할**: 바코드/PDF/이미지 일괄 스캔 진입점.
- **순서**:
  1. **"PDF 파일 선택"** 클릭 → 입고 서류 PDF 선택.
  2. 시스템이 자동으로 LOT 번호·수량 추출.
  3. 추출된 내용 확인 후 **"저장"** 클릭.
  4. Pending 화면으로 자동 이동.

---

### 화면 9. Log (로그)

- **역할**: 모든 작업 기록. 오류 났을 때 여기서 확인해요.
- **순서 (오류 추적)**:
  1. 좌측 메뉴 **Log** 클릭.
  2. **필터: 레벨** 드롭다운에서 **"ERROR"** 선택.
  3. 가장 위쪽 행이 최근 에러. **클릭**하면 상세 메시지가 아래에 떠요.
  4. 오류 메시지를 복사(드래그 → Ctrl+C) 해서 담당자에게 보내 주세요.

---

## 4. 자주 나는 오류 Q&A

### Q1. "프로그램이 안 켜져요" (회색 창도 안 떠요)

- **원인 1**: `C:\Python314\pythonw.exe` 가 없어요.
  - **해결**: IT 담당자에게 "Python 3.14 가 설치 안 돼 있어요" 라고 연락.
- **원인 2**: 이전 실행이 완전히 안 꺼졌어요.
  - **해결**: **Ctrl + Shift + Esc** → 작업 관리자 → **세부 정보** 탭 → `pythonw.exe` 모두 선택 → **작업 끝내기**.
- **원인 3**: 인터넷/회사 방화벽이 막혔어요 (AI 파싱 기능 쓸 때).
  - **해결**: 입고 PDF만 쓸 때는 인터넷 없어도 돼요. AI 자동 채우기(보라색 버튼)는 잠시 사용 불가.

### Q2. "백엔드 연결 안 됨" 또는 "API 500" 토스트

- **원인**: 내부 서버가 시작하다 실패했어요.
- **해결**:
  1. **Log** 메뉴 → **ERROR** 필터 → 가장 위 메시지 확인.
  2. 메시지에 `no such table` 이 있으면 → IT 담당자에게 "DB 마이그레이션 실패" 라고 연락.
  3. 메시지에 `port already in use` 이면 → Q1 의 작업 관리자 방법으로 이전 `pythonw.exe` 다 끝내기.

### Q3. "PDF 읽었는데 LOT 가 0개예요"

- **원인 1**: PDF 가 스캔본(이미지)인데 OCR 이 글자를 못 읽었어요.
  - **해결**: **"OCR 재시도"** 버튼 클릭. 그래도 안 되면 IT 담당자.
- **원인 2**: PDF 가 손글씨 / 한글 번짐.
  - **해결**: 화면 우측 **"수동 입력"** 으로 LOT 한 줄씩 입력.

### Q4. "저장 버튼 눌렀는데 반응이 없어요"

- **원인**: 같은 LOT 가 이미 있어서 중복 차단.
- **해결**:
  1. **Log** 메뉴 → `DUPLICATE` 로 검색.
  2. 해당 LOT 의 기존 위치를 확인하고 **"병합"** 또는 **"기존 것 사용"** 선택.

### Q5. "스캔했는데 Picked 화면이 안 바뀌어요"

- **원인**: 바코드가 잘못된 LOT 라서 차단.
- **해결**:
  1. 화면 하단 토스트에 **"차단 사유: ..."** 메시지가 떠요. 메시지 복사.
  2. IT 담당자에게 보내 주세요. 보통 **allocation 미등록 LOT** 이라서 Allocation 화면에서 위치 배정 후 재시도.

### Q6. "오류 메시지에 `initial_weight` 어쩌고 나옴"

- **원인**: LOT 무게 무결성 오류 (SOLD 후 잔량 0 처리 잘못).
- **해결**: **반드시 IT 담당자에게 연락**. 직접 고치면 안 돼요.

### Q7. "창은 떴는데 화면이 하얘요"

- **원인**: 백엔드 API 응답 지연.
- **해결**:
  1. 5~10초 기다려 주세요.
  2. 안 뜨면 **F5** 키로 새로고침.
  3. 두 번 새로고침해도 안 뜨면 **Q2** 참고.

## 5. 그래도 안 되면: 담당자 연락 전 준비

연락처: IT 담당자 (남기동 대표 직접 연락 — 010-xxxx-xxxx)

연락 전 아래 두 가지를 캡처/저장해 주세요. **이게 없으면 원격 진단이 어렵습니다.**

1. **오류 화면 캡처**
   - `PrintScreen` 키 → 그림판 → `Ctrl+V` → 저장
   - 또는 `Win + Shift + S` 로 부분 캡처
2. **로그 파일** (`logs\sqm_inventory.log`)
   - 파일 탐색기에서 `D:\program\sqm\SQM_inventory\logs\sqm_inventory.log` 파일을 찾아서
   - 그 파일을 **바탕화면**에 복사 (Ctrl+C → Ctrl+V)
   - 마지막 100줄 정도만 봐도 충분해요. (메모장으로 열어서 `Ctrl+End`)

전달할 때:
- 무엇을 하려고 했는지 (예: "LOT ABC-001 출고 시작 누름")
- 어떤 결과가 나왔는지 (예: "토스트에 'API 500' 뜸")
- 위 두 파일 (스크린샷 + 로그)
