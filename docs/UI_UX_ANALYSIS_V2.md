# 🎯 SQM UI/UX 심층 분석 리포트 v2

## 📊 추가 발견된 문제점

### ❌ 문제점 5: 기능 중복 (심각)

```
"입고" 기능이 존재하는 곳:

1. 툴바 → [📥 입고 ▼] 메가 버튼
2. 메뉴바 → 파일 → 입고
3. 대시보드 → 빠른 액션 → 📥 PDF 입고

→ 사용자: "도대체 어디서 해야 하지?" 🤯
```

**해결책**: 대시보드 "빠른 액션" 제거 또는 역할 변경

---

### ❌ 문제점 6: 대시보드 정체성 혼란

```
현재 대시보드:
┌─────────────────────────────────────────┐
│  [카드] [카드] [카드] [카드] [카드]     │  ← 현황 (좋음)
├─────────────────────────────────────────┤
│  [알림 패널]     │  [빠른 액션]         │  ← 액션? (문제)
├─────────────────────────────────────────┤
│  [제품별 요약]   │  [최근 활동]         │  ← 현황 (좋음)
└─────────────────────────────────────────┘

문제: 대시보드가 "현황 파악" vs "액션 실행" 역할 혼재
```

**해결책**: 대시보드는 순수하게 "현황 파악"에 집중

---

### ❌ 문제점 7: 재고/톤백 탭 컨텍스트 액션 부족

```
재고 탭 현재:
┌─────────────────────────────────────────┐
│ 검색: [     ] 상태: [전체 ▼]            │  ← 필터만 있음
├─────────────────────────────────────────┤
│ LOT_NO | 제품 | SAP | 입고 | 잔량 |... │
│ ─────────────────────────────────────── │
│ LOT-001| SQM  | ... | 25MT | 20MT |... │
└─────────────────────────────────────────┘

문제: 선택 후 할 수 있는 액션이 없음 (더블클릭만)
```

**해결책**: 탭 내부에 컨텍스트 액션 버튼 추가
