## 📥 입고 처리 (3단계)

### 방법 1: PDF 드래그 앤 드롭 ⭐추천
```
1. PDF 파일을 프로그램 창에 드래그
2. 자동 파싱 → 미리보기 확인
3. [입고 확정] 클릭
```

### 방법 2: 메뉴 사용
```
1. [파일] → [📥 입고 파일 업로드] (또는 Ctrl+I)
2. PDF 선택
3. [입고 확정] 클릭
```

---

## 📤 출고 처리 (2가지 방법)

### 방법 1: 간편 출고 ⭐추천
```
1. Ctrl+O (또는 [파일] → [📤 출고] → [간편 출고])
2. LOT 번호 선택 또는 입력
3. 출고 수량 입력
4. [출고] 클릭
```

### 방법 2: 배정표 출고 (대량)
```
1. [파일] → [📤 출고] → [배정표 출고 (Excel)]
2. 배정표 Excel 파일 선택
3. 미리보기 확인 후 [출고 확정]
```

---

## 💾 Excel 내보내기

```
1. Ctrl+E (또는 [파일] → [💾 내보내기])
2. 양식 선택:
   - 📑 통합 재고현황 ★추천
   - 📋 기존 양식 (통관요청)
   - 📊 루비리 양식 (18컬럼)
   - 📦 톤백 현황 (Sub LOT)
3. 저장 위치 선택
```

---

## 🔐 백업 (매일 권장)

```
1. Ctrl+B (또는 [파일] → [🔐 백업/복원] → [지금 백업])
2. 백업 완료 메시지 확인
```

**백업 파일 위치**: `data/db/backups/`

## 📊 대시보드 활용 (v3.2 신규)

시작 시 자동으로 대시보드 탭이 열립니다.

| 영역 | 내용 |
|------|------|
| **요약 카드** | 총 재고, LOT 수, 금일 입출고, 가용 톤백 |
| **알림 패널** | 재고 부족 경고, 장기 미출고, 무결성 이슈 |
| **빠른 액션** | PDF 입고, 출고, 검색, 보고서, 백업 버튼 |
| **제품별 현황** | 제품별 LOT 수, 재고량, 상태 |

**자동 새로고침**: 30초마다 (ON/OFF 가능)

## ❓ 문제 해결

### "LOT 번호가 이미 존재합니다"
→ 동일 LOT 중복 입고 방지. 정상 동작입니다.

### "재고 부족"
→ 출고하려는 수량이 현재 재고보다 많습니다.

### 프로그램이 느려요
→ [도구] → [🔧 DB 최적화] 실행

### 데이터 복구가 필요해요
→ [파일] → [🔐 백업/복원] → [백업에서 복원]
