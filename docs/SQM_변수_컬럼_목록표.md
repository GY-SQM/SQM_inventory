## 표 파일 위치

- **폴더:** 프로젝트 루트 아래 **`docs/`**
- **엑셀 파일 전체 경로 예:** `d:\프로그램\Sqm\SQM_v590\docs\SQM_변수_테이블_문서.xlsx`

### 한 번에 보기 — 엑셀 한 파일 (시트 5개: 목차 + 데이터 4개)

| 파일명 | 설명 |
|--------|------|
| **SQM_변수_테이블_문서.xlsx** | **요청하신 변수·테이블 데이터가 모두 들어 있습니다.** 목차 + 매트릭스 2개 + 변수 2개 시트. |

| 시트 이름 | 내용 |
|-----------|------|
| **목차** | 파일 위치, 시트 설명, 요청 사항 대비 |
| 매트릭스_공통헤더 | 테이블 × 공통 헤더 (O 표시) |
| 매트릭스_단일헤더 | 테이블 × 단일 테이블 전용 헤더 |
| 변수_DB컬럼 | DB 컬럼: 변수명, 의미, 타입, 사용처(테이블) 전부 |
| 변수_상수 | 비즈니스 상수: 변수명, 의미, 타입, 사용처 전부 |

엑셀 파일을 다시 만들려면: `python docs/build_sqm_docs_excel.py` 실행 (프로젝트 루트에서).

### CSV만 따로 쓰는 경우

| 파일명 | 설명 |
|--------|------|
| **SQM_변수_컬럼_목록_DB컬럼.csv** | DB 컬럼(데이터 헤더): 변수명, 의미, 타입, 사용처(테이블) |

CSV를 엑셀에서 열 때 **데이터 → 텍스트/CSV** 로 불러온 뒤 **UTF-8** 인코딩을 선택하면 한글이 정상 표시됩니다.
