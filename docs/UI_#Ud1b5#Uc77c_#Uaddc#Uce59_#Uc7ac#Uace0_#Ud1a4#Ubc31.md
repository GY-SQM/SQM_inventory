# UI 통일 규칙: 재고 리스트 ↔ 톤백 리스트 (v5.5.2)

## 기준
- **재고 리스트(Inventory)** UI가 **기준**입니다.
- **톤백 리스트(Ton Bag)** 는 재고 리스트와 **같은 화면 구성·순서**를 따릅니다.

## 화면 구성 (동일 순서)
1. **필터 바** — "🔽 필터:" + LOT NO, SAP NO, BL NO, CONTAINER, PRODUCT, STATUS + "✖ 초기화"
2. **표시 컬럼 바** — "표시 컬럼:" + 체크박스 6개 (재고·톤백 동일: SAP NO, BL NO, CONTAINER, SHIP DATE, FREE TIME, CUSTOMS)
3. **트리뷰** — 데이터 테이블
4. **통계/액션 바** — 재고: LOT·톤백·입고·잔량·출고·가용·소진·출고율 / 톤백: 일괄 출고·라벨·Excel·UID 복사·위치 업로드·출고 취소 + 선택/합계 + 총·가용·출고 + 상태·샘플·검색
5. **하단 합계/푸터** — FooterTotalBar

## 유지보수 규칙
- **재고 리스트** UI를 바꾸면(필터 컬럼 추가/삭제, 표시 컬럼 변경, 버튼/통계 바 순서 등) **톤백 리스트**도 같은 방식으로 반영할 것.
- 수정 시 참고 파일:
  - 재고: `gui_app_modular/tabs/inventory_tab.py`
  - 톤백: `gui_app_modular/tabs/tonbag_tab.py`
- 톤백은 필터 바를 **1개만** 사용 (재고와 동일). 중복 필터 바를 두지 않음.
