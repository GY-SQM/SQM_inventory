# SQM 재고관리 — 메뉴 및 하부 메뉴 기능 정리

> 기준: **커스텀 메뉴바** (`custom_menubar.py`). 네이티브 메뉴/툴바 드롭다운과 항목명이 약간 다를 수 있음.

---

## 1. 📁 파일

| 하부 메뉴 | 기능 |
|-----------|------|
| **📥 입고 (Ctrl+I)** | (서브메뉴) |
| ↳ 📄 PDF 입고 (원스톱) | PDF(B/L·D/O·P/L 등) 업로드 → 원스톱 입고 다이얼로그에서 파싱·매핑 후 일괄 입고 |
| ↳ 📊 Excel 입고 | 재고 리스트 형식 엑셀 업로드(템플릿 열기 또는 파일 선택) → 검증 후 일괄 입고 |
| ↳ 📋 D/O 후속 연결 | 이미 입고된 LOT에 D/O(도착일·Free Time 등) 정보를 나중에 연결 |
| ↳ 🔄 반품 (재입고) | 반품 엑셀(재고 리스트 형식 + 반품 수량/사유) 업로드 → 재입고 처리 |
| **💾 내보내기 (Ctrl+E)** | (서브메뉴) |
| ↳ 📋 통관요청 양식 | 통관요청용 엑셀 양식 다운로드/내보내기 |
| ↳ 📊 루비리 양식 | 루비리 양식 엑셀 내보내기 |
| ↳ 📦 톤백 현황 | 톤백(언로케이션) 리스트 엑셀 내보내기 |
| ↳ 📑 통합 현황 ★ | 통합 현황 엑셀 내보내기 (추천) |
| **🔐 백업 (Ctrl+B)** | (서브메뉴) |
| ↳ 💾 백업 생성 | 현재 DB를 백업 파일로 저장 |
| ↳ 🔄 복원 | 저장된 백업 파일로 DB 복원 |
| ↳ 📋 백업 목록 | 백업 파일 목록 조회 |
| ↳ ⏰ 자동 백업 설정 | 자동 백업 간격(30분/1시간/3시간 등) 설정 |
| **🔧 도구** | (서브메뉴) |
| ↳ 📄 PDF 변환 | (아래 PDF 변환 항목과 동일) |
| ↳ 🩺 데이터 정합성 검사 | 재고·톤백·LOT 간 데이터 정합성 검사 및 리포트 |
| **📂 최근 파일** | 최근 연 DB/파일 목록 (선택 시 해당 파일 열기) |
| **종료** | 프로그램 종료 |

## 2. 🔧 도구

| 하부 메뉴 | 기능 |
|-----------|------|
| **📦 컨테이너 구분** | 체크 시 재고/톤백의 CONTAINER 열에 접미사(-1, -2 등) 표시 |
| **📋 D/O 후속 연결** | 파일 메뉴와 동일 — 입고된 LOT에 D/O 정보 후속 연결 |
| **📄 PDF 변환** | (서브메뉴) |
| ↳ → Excel | PDF → 엑셀 변환(단일 파일) |
| ↳ → Word | PDF → 워드 변환 |
| ↳ 📁 일괄 변환 | PDF 여러 개 일괄 엑셀 변환 |
| ↳ 🔍 PDF 분석 | PDF 내용 분석(텍스트/테이블 등) |
| **📷 문서 변환 (OCR/PDF)** | OCR·PDF 문서 변환 다이얼로그 |
| **📋 PDF 보고서** | (서브메뉴) |
| ↳ 📦 재고 현황 보고서 | 재고 현황 PDF 생성 |
| ↳ 📈 입출고 내역 | 입출고 내역 PDF |
| ↳ 📝 거래 명세서 | 거래 명세서 PDF |
| ↳ 📤 출고 확인서 | 출고 확인서 PDF |
| ↳ 🔖 LOT 상세 | LOT 상세 PDF |
| ↳ 📊 일일 현황 PDF | 일일 현황 PDF (v398) |
| ↳ 📅 월간 실적 PDF | 월간 실적 PDF (v398) |
| **🩺 데이터 정합성 검사** | 정합성 검사 실행 및 결과 표시 |
| **🤖 AI 어시스턴트** | (서브메뉴, HAS_GEMINI 시) |
| ↳ API 사용 | 체크 시 Gemini API 사용 on/off |
| ↳ 💬 AI 채팅 | AI 채팅 창 열기 |
| ↳ ⚙️ API 설정 | Gemini API 키 등 설정 |
| ↳ 🔬 API 테스트 | API 연결 테스트 |
| **🛡️ DB 보호** | (서브메뉴, HAS_DB_PROTECTION 시) |
| ↳ 🔍 무결성 검증 | DB 체크섬 등 무결성 검증 |
| ↳ 📋 작업 로그 | DB 작업 로그 조회 |
| ↳ 💾 로그 내보내기 | 작업 로그 파일로 내보내기 |
| ↳ 🔄 체크섬 갱신 | DB 체크섬 갱신 |
| **🔍 DB 검사** | DB 무결성·스키마 검사 |
| **🔧 DB 최적화** | VACUUM 등 DB 최적화 |
| **📋 로그 정리** | 로그 파일 정리 |
| **ℹ️ DB 정보** | DB 경로·크기·테이블 등 정보 표시 |
| **🗑️ 테스트 DB 초기화 (데이터 삭제)** | 테스트용 DB 초기화(데이터 삭제) — 메뉴에서만 호출 |
| **✨ 고급** | (서브메뉴, HAS_FEATURES 시) |
| ↳ 🔬 입고 검증 | 입고 Dry Run(실제 반영 없이 검증) |
| ↳ 🔬 출고 검증 | 출고 Dry Run |
| ↳ 🩺 전체 진단 | 전체 자가 진단 |
| ↳ 🧪 단위 테스트 | 단위 테스트 러너 다이얼로그 |
