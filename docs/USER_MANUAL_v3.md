## 1. 시작하기

### 1.1 시스템 요구사항

| 항목 | 최소 사양 | 권장 사양 |
|------|----------|----------|
| OS | Windows 10 | Windows 11 |
| RAM | 4GB | 8GB+ |
| 저장공간 | 500MB | 2GB+ |
| Python | 3.10+ | 3.12+ |

### 1.2 설치

```bash
# 1. 압축 해제
unzip sqm_v3.0.zip

# 2. 의존성 설치
cd sqm_v3.0
pip install -r requirements.txt

# 3. 실행
python run.py
```

### 1.3 첫 실행

1. 프로그램 실행 시 자동으로 데이터베이스가 생성됩니다
2. 공유폴더 경로 설정: `설정 > 데이터베이스 경로`
3. Gemini API 키 설정 (PDF 파싱용): `설정 > API 설정`

## 3. 입고 처리

### 3.1 단일 LOT 입고

1. `파일 > 입고` 또는 툴바 `📥입고` 클릭
2. 입고 정보 입력:
   - **LOT 번호** (필수): 예) 112PERF0001
   - **중량** (필수): kg 단위
   - **제품 유형**: Li2CO3, NiSO4 등
   - **SAP 코드**: 예) 2200033057
   - **입고일**: YYYY-MM-DD
3. `입고 처리` 버튼 클릭

### 3.2 대량 입고 (Excel)

1. `파일 > Excel 가져오기`
2. Excel 파일 선택
3. 컬럼 매핑 확인
4. `가져오기` 클릭

**Excel 형식:**
| LOT번호 | 중량(kg) | 제품유형 | SAP코드 | 입고일 |
|---------|----------|----------|---------|--------|
| 112PERF0001 | 1000 | Li2CO3 | 2200033057 | 2025-01-15 |

### 3.3 PDF 자동 입고

1. `파일 > PDF 입고` 또는 PDF 드래그앤드롭
2. Packing List, Invoice, B/L, D/O 자동 인식
3. 파싱 결과 확인 후 `입고 처리`

## 4. 출고 처리

### 4.1 LOT 출고

1. Inventory 탭에서 LOT 선택
2. 우클릭 > `출고` 또는 `📤출고` 버튼
3. 출고 수량 입력
4. `출고 처리` 클릭

### 4.2 톤백 직접 출고

1. Tonbags 탭에서 출고할 톤백 선택 (복수 선택 가능)
2. 우클릭 > `선택 톤백 출고`
3. 확인 후 출고

### ⚠️ v3.0 중요 규칙

> **톤백 부분 출고 불가**
> 
> - 톤백은 전량(AVAILABLE) 또는 판매완료(SOLD) 상태만 존재
> - 출고량이 톤백 무게보다 작으면 해당 톤백은 출고되지 않음
> - 예: 100kg 톤백에서 50kg만 출고 불가

**예시:**
- LOT 총 재고: 1000kg (100kg × 10개 톤백)
- 출고 요청: 350kg
- 결과: 3개 톤백 출고 (300kg), 50kg 미출고

## 5. 재고 조회

### 5.1 전체 재고

Inventory 탭에서 전체 LOT 재고 확인

### 5.2 검색

Search 탭 또는 `Ctrl+F`:
- LOT 번호 검색
- 제품 유형 필터
- 상태 필터 (ACTIVE/DEPLETED)
- 날짜 범위 검색

### 5.3 LOT 상세

LOT 더블클릭 시 상세 정보:
- 입고 정보
- 톤백 목록
- 출고 이력
- Sub LOT 현황

## 6. 톤백 관리

### 6.1 톤백 상태

| 상태 | 설명 | 재고 기여 |
|------|------|----------|
| **AVAILABLE** | 출고 가능 | 전량 |
| **SOLD** | 출고 완료 | 0 |
| **PICKED** | 피킹 중 | 전량 |
| **RESERVED** | 예약 | 전량 |

### 6.2 톤백 조회

Tonbags 탭:
- LOT별 톤백 목록
- 상태별 필터
- 무게 정렬

### 6.3 무결성 검증 (v3.0)

`도구 > 톤백 무결성 검증`:
- current_weight ≠ SUM(AVAILABLE 톤백) 감지
- 자동 수정 옵션

## 7. PDF 문서 처리

### 7.1 지원 문서

| 문서 | 추출 정보 |
|------|----------|
| Packing List | LOT, 중량, 제품정보 |
| Invoice | 금액, 거래처, LOT |
| B/L | 선적정보, 도착일 |
| D/O | 출고지시, 수량 |

### 7.2 PDF 파싱

1. PDF 파일 드래그앤드롭 또는 `파일 > PDF 열기`
2. 문서 유형 자동 감지
3. 파싱 결과 미리보기
4. 수정 후 `입고 처리`

### 7.3 OCR 설정 (v3.0)

`설정 > OCR 설정`:
- API 키 설정
- 동시성 설정 (1-5)
- 자동 튜닝 활성화

> **자동 튜닝**: 429 오류 발생 시 자동으로 동시성 감소

## 9. 문제 해결

### 9.1 에러 다이얼로그 (v3.0)

에러 발생 시:
- **📋 로그 복사**: 클립보드에 에러 로그 복사
- **📂 로그 열기**: 로그 파일 직접 열기
- **🔄 재시도**: 작업 재시도

### 9.2 자주 묻는 질문

**Q: LOT 번호가 중복된다고 나옵니다**
> A: 이미 입고된 LOT입니다. 기존 LOT에 추가 입고하려면 "추가 입고" 기능을 사용하세요.

**Q: 출고 시 수량이 맞지 않습니다**
> A: v3.0부터 톤백 부분 출고가 불가합니다. 톤백 단위로만 출고됩니다.

**Q: PDF 파싱이 안됩니다**
> A: Gemini API 키가 설정되어 있는지 확인하세요. `설정 > API 설정`

**Q: 공유폴더에서 느립니다**
> A: 네트워크 상태를 확인하세요. v3.0의 부드러운 진행률 기능이 체감 속도를 개선합니다.

### 9.3 로그 파일

위치: `logs/` 폴더
- `app_YYYYMMDD.log`: 일별 로그
- 문제 발생 시 이 파일을 첨부해 주세요

## 10. v3.0 신규 기능

### 10.1 톤백 부분출고 불가 규칙

- **이전**: 톤백에서 일부 수량만 출고 가능
- **v3.0**: 톤백 전량 출고만 가능 (AVAILABLE → SOLD)
- **장점**: 재고 계산 단순화, 오류 방지

### 10.2 OCR 자동 튜닝

- 429 Rate Limit 자동 감지
- 동시성 자동 조절 (1-5)
- Circuit Breaker 패턴

### 10.3 UI 운영 편의

- 에러 발생 시 로그 열기/복사 버튼
- 미완료 작업 자동 복구
- 공유폴더 대응 부드러운 진행률

### 10.4 톤백 무결성 검증

- current_weight = SUM(AVAILABLE 톤백) 검증
- 불일치 시 자동 수정 옵션
