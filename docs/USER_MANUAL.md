## 1. 시작하기

### 1.1 프로그램 설치

#### 필요 사항
- Windows 10 이상
- Python 3.8 이상 (설치 안내는 아래 참조)
- 화면 해상도 1920x1080 권장

#### Python 설치 방법

1. https://www.python.org/downloads/ 접속
2. "Download Python 3.x.x" 클릭
3. 다운로드된 파일 실행
4. **⚠️ 중요**: "Add Python to PATH" 체크 후 Install

```
┌─────────────────────────────────────────┐
│  ☑ Add Python 3.x to PATH    ← 반드시! │
│  [Install Now]                          │
└─────────────────────────────────────────┘
```

#### 프로그램 설치 방법

1. `sqm_inventory_v2.9.67.zip` 파일을 원하는 폴더에 압축 해제
2. 압축 해제된 폴더로 이동
3. `install.bat` 더블클릭 (필요한 라이브러리 자동 설치)

### 1.2 프로그램 실행

```
방법 1: gui_app.py 더블클릭
방법 2: run_inventory.bat 더블클릭 (있는 경우)
방법 3: 명령 프롬프트에서 python gui_app.py 실행
```

### 1.3 첫 화면

프로그램을 처음 실행하면 다음과 같은 화면이 나타납니다:

## 2. 화면 구성

### 2.1 메뉴바

| 메뉴 | 기능 |
|------|------|
| **파일(F)** | 새 DB, DB 열기, 내보내기, 종료 |
| **편집(E)** | 복사, 붙여넣기, 선택 삭제 |
| **보기(V)** | 새로고침, 검색 패널, 통계 패널 |
| **도구(T)** | 설정, DB 백업, 정합성 검사 |
| **도움말(H)** | 사용 설명서, 버전 정보 |

### 2.2 탭 설명

| 탭 | 아이콘 | 용도 |
|-----|--------|------|
| **입고** | 📥 | 신규 입고 등록, 패킹리스트 업로드 |
| **재고** | 📦 | 현재 재고 조회, LOT별 상세 확인 |
| **톤백** | 📋 | 톤백 단위 조회, 위치 관리 |
| **출고** | 📤 | 출고 처리, 출고 지시서 업로드 |
| **리포트** | 📊 | 각종 리포트 생성 및 출력 |

### 2.3 상태바

화면 하단에 현재 상태가 표시됩니다:

```
┌─────────────────────────────────────────────────────────────────┐
```

## 3. 입고 업무

### 3.1 입고란?

배가 도착해서 컨테이너가 창고에 들어오는 것을 "입고"라고 합니다.

```
선박 도착 → 컨테이너 하역 → 창고 입고 → 시스템 등록
```

### 3.2 입고 방법 1: Excel 파일 업로드 (권장)

#### 단계별 안내

**1단계: 입고 탭 클릭**
```
[📥 입고] ← 이 탭 클릭
```

**2단계: 파일 선택**
```
┌─────────────────────────────────────────┐
│  [📂 패킹리스트 업로드]  ← 클릭        │
└─────────────────────────────────────────┘
```

**3단계: Excel 파일 선택**
- 패킹리스트 Excel 파일 선택
- 지원 형식: .xlsx, .xls

**4단계: 미리보기 확인**
```
┌─────────────────────────────────────────────────────────────┐
│ 미리보기                                                    │
├─────────────────────────────────────────────────────────────┤
│ LOT 번호     │ 제품명              │ 수량  │ 중량(MT)       │
│ 1125080001   │ NICKEL SULFATE...   │ 15    │ 7.50          │
│ 1125080002   │ NICKEL SULFATE...   │ 20    │ 10.00         │
│ ...                                                         │
├─────────────────────────────────────────────────────────────┤
│ 총 4개 LOT, 70개 톤백, 35.00 MT                             │
└─────────────────────────────────────────────────────────────┘
```

**5단계: 입항일/입고일 설정**
```
┌─────────────────────────────────────────┐
│ 입항일: [2025-01-15] 📅                 │
│ 입고일: [2025-01-18] 📅                 │
└─────────────────────────────────────────┘
```
- 입항일: 배가 항구에 도착한 날짜
- 입고일: 실제 창고에 입고된 날짜

**6단계: 입고 실행**
```
┌─────────────────────────────────────────┐
│  [✅ 입고 실행]  ← 클릭                 │
└─────────────────────────────────────────┘
```

**7단계: 완료 확인**
```
┌─────────────────────────────────────────┐
│ ✅ 입고 완료!                           │
│                                         │
│ - 처리된 LOT: 4개                       │
│ - 생성된 톤백: 70개                     │
│ - 총 입고량: 35.00 MT                   │
│                                         │
│              [확인]                     │
└─────────────────────────────────────────┘
```

### 3.3 입고 방법 2: 수동 입력

**1단계: 수동 입력 버튼 클릭**
```
[✏️ 수동 입력] ← 클릭
```

**2단계: 정보 입력**
```
┌─────────────────────────────────────────────────────────────┐
│ 신규 입고 등록                                              │
├─────────────────────────────────────────────────────────────┤
│ SAP 번호:     [SAP202500001        ]                        │
│ B/L 번호:     [MAEU2500001234      ]                        │
│ 컨테이너 번호: [FFAU5355006-1       ]                        │
│ LOT 번호:     [1125080001          ]  ← 필수!               │
│ 제품명:       [NICKEL SULFATE HEX... ▼]                     │
│ 톤백 수량:    [15                  ]                        │
│ 총 중량(MT):  [7.5                 ]                        │
│ 입항일:       [2025-01-15] 📅                               │
│ 입고일:       [2025-01-18] 📅                               │
├─────────────────────────────────────────────────────────────┤
│            [취소]        [등록]                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.4 입고 시 주의사항

| 항목 | 주의사항 |
|------|----------|
| **LOT 번호** | 중복 불가! 이미 있는 LOT는 입고 불가 |
| **톤백 수량** | 실제 수량과 정확히 일치해야 함 |
| **중량** | MT(톤) 단위로 입력 (예: 7.5 MT) |
| **날짜** | 입항일 ≤ 입고일 확인 |

### 3.5 입고 취소

잘못 입고한 경우:

```
1. 재고 탭에서 해당 LOT 선택
2. 마우스 우클릭 → "입고 취소"
3. 확인 메시지에서 "예" 클릭

⚠️ 주의: 이미 출고된 LOT는 취소 불가!
```

### 4.2 검색 기능

```
┌─────────────────────────────────────────────────────────────┐
│ 검색: [_______________] [🔍 검색] [↻ 초기화]               │
│                                                             │
│ 검색 조건:                                                  │
│ ☑ LOT 번호   ☑ SAP 번호   ☑ 제품명   ☐ 컨테이너           │

```

**검색 예시:**
- `1125` → LOT 번호에 1125가 포함된 모든 항목
- `NICKEL` → 제품명에 NICKEL이 포함된 모든 항목

### 4.3 정렬 기능

컬럼 헤더 클릭으로 정렬:

```

            두 번째 클릭: 내림차순 (Z→A)
```

## 5. 출고 업무

### 5.1 출고란?

고객 주문에 따라 창고에서 제품을 내보내는 것을 "출고"라고 합니다.

```
고객 주문 → 출고 지시서 → 톤백 피킹 → 배송
```

### 5.2 출고 방법 1: Excel 파일 업로드 (권장)

**1단계: 출고 탭 클릭**
```
[📤 출고] ← 이 탭 클릭
```

**2단계: 출고 지시서 업로드**
```
┌─────────────────────────────────────────┐
│  [📂 출고 지시서 업로드]  ← 클릭       │
└─────────────────────────────────────────┘
```

**3단계: 미리보기 확인**
```
┌─────────────────────────────────────────────────────────────┐
│ 출고 미리보기                                               │
├─────────────────────────────────────────────────────────────┤
│ LOT 번호     │ 출고 수량(MT) │ 출고처      │ 가용재고(MT)  │
│ 1125080001   │ 2.50          │ POSCO       │ 6.00 ✅       │
│ 1125080002   │ 3.00          │ LG ENERGY   │ 10.00 ✅      │
│ 1125080003   │ 5.00          │ SK ON       │ 3.00 ⚠️       │
├─────────────────────────────────────────────────────────────┤
│ ⚠️ 1125080003: 요청 5.00 MT, 가용 3.00 MT (부족!)          │
└─────────────────────────────────────────────────────────────┘
```

**4단계: 출고 실행**
```
┌─────────────────────────────────────────┐
│  [✅ 출고 실행]  ← 클릭                 │
└─────────────────────────────────────────┘
```

### 5.3 출고 방법 2: 수동 선택

**1단계: 재고 탭에서 LOT 선택**
```
LOT를 선택 (Ctrl+클릭으로 여러 개 선택 가능)
```

**2단계: 출고 버튼 클릭**
```
[📤 선택 출고] ← 클릭
```

**3단계: 출고 정보 입력**
```
┌─────────────────────────────────────────────────────────────┐
│ 출고 처리                                                   │
├─────────────────────────────────────────────────────────────┤
│ 선택된 LOT: 1125080001                                      │
│ 가용 재고: 6.00 MT (12개 톤백)                              │
│                                                             │
│ 출고 수량(MT): [2.5         ]                               │
│ 출고처:        [POSCO                  ]                    │
│ 판매 참조:     [SALE-2025-0001         ]                    │
├─────────────────────────────────────────────────────────────┤
│            [취소]        [출고]                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.4 랜덤/지정 출고 방식

**랜덤/지정 = Random or Selected (랜덤 또는 지정된 톤백 출고)**

```
예시: LOT에 톤백 1~15번이 있을 때

입고 순서: 1번 → 2번 → ... → 15번
출고 순서: 15번 → 14번 → 13번 → ...

WHY? 
- 창고에서 가장 위에 있는 것(나중에 쌓인 것)부터 꺼내기 쉬움
- 시스템이 자동으로 랜덤/지정 적용
```

## 6. 반품 처리

### 6.1 반품이란?

출고된 제품이 다시 창고로 돌아오는 것을 "반품"이라고 합니다.

```
고객 반품 요청 → 제품 회수 → 창고 입고 → 시스템 등록
```

### 6.2 반품 처리 방법

**1단계: 톤백 탭에서 SOLD 상태 톤백 선택**
```
상태가 "SOLD"인 톤백 선택
```

**2단계: 반품 버튼 클릭**
```
[↩️ 반품 처리] ← 클릭
```

또는 마우스 우클릭 → "반품 처리"

**3단계: 반품 정보 입력**
```
┌─────────────────────────────────────────────────────────────┐
│ 반품 처리                                                   │
├─────────────────────────────────────────────────────────────┤
│ LOT 번호: 1125080001                                        │
│ 톤백 번호: 15                                               │
│                                                             │
│ 반품 방식:                                                  │
│ ◉ 특정 톤백 반품 (선택된 톤백)                              │
```

## 8. 자주 묻는 질문

### Q1. 프로그램이 실행되지 않아요

```
A: 다음을 확인해주세요:
1. Python이 설치되어 있나요? (cmd에서 python --version 확인)
2. 필요한 라이브러리가 설치되어 있나요? (install.bat 실행)
3. 관리자 권한으로 실행해보세요
```

### Q2. 이미 있는 LOT를 다시 입고하려고 하면 오류가 나요

```
A: LOT 번호는 고유해야 합니다.
- 같은 LOT 번호로 중복 입고 불가
- 실수로 입고한 경우 → 먼저 삭제 후 다시 입고
```

### Q3. 출고 후 재고가 맞지 않아요

```
A: 정합성 검사를 실행해주세요:
1. 메뉴 → 도구 → 정합성 검사
2. 불일치 항목이 있으면 표시됨
3. 문제가 지속되면 개발팀에 문의
```

### Q4. 반품 처리 시 새로운 LOT 번호가 부여되나요?

```
A: 아니요, 원래 LOT 번호가 유지됩니다.
- 반품 시 원래 LOT 번호 그대로 사용
- 새로운 LOT 번호 부여 안 함
```

### Q5. 여러 사람이 동시에 사용할 수 있나요?

```
A: 네, 가능합니다. 단, 주의사항:
- DB 파일이 공유 폴더에 있어야 함
- 동시 작업 시 충돌 가능성 있음
- 중요 작업 전 새로고침 권장
```

### Q6. 데이터를 백업하고 싶어요

```
A: 두 가지 방법이 있습니다:
1. 메뉴 → 도구 → DB 백업 (자동 백업)
2. inventory.db 파일을 직접 복사 (수동 백업)
```

### Q7. 프로그램이 느려요

```
A: 다음을 시도해보세요:
1. 프로그램 재시작
2. 검색 결과 제한 (너무 많은 데이터 표시 시)
3. 오래된 데이터 정리 (도구 → 데이터 정리)
```

## 9. 문제 해결

### 9.1 오류 메시지별 해결 방법

#### "database is locked"
```
원인: 다른 프로그램이나 사용자가 DB를 사용 중
해결:
1. 잠시 후 다시 시도
2. 다른 Excel 프로그램 종료
3. 프로그램 재시작
```

#### "UNIQUE constraint failed"
```
원인: 중복된 데이터 입력 시도
해결:
1. 이미 존재하는 LOT/톤백인지 확인
2. 중복 데이터 삭제 후 재시도
```

#### "No such table"
```
원인: DB 테이블이 없거나 손상됨
해결:
1. 메뉴 → 도구 → DB 초기화
2. 또는 새 DB 파일 생성
```

#### 화면이 멈춤 (응답 없음)
```
원인: 대량 데이터 처리 중
해결:
1. 잠시 대기 (처리 중일 수 있음)
2. 10분 이상 지속 시 → 프로그램 강제 종료 후 재시작
```

### 9.2 로그 파일 확인

문제 발생 시 로그 파일 확인:

```
위치: 프로그램폴더/logs/
파일: inventory_YYYYMMDD.log

최근 오류는 파일 끝부분에 있음
```

### 9.3 기술 지원 요청 시

다음 정보를 함께 제공해주세요:

```
1. 프로그램 버전 (도움말 → 버전 정보)
2. 오류 메시지 전체 내용
3. 오류 발생 시점의 작업 내용
4. 로그 파일 (가능하면)
5. 스크린샷 (가능하면)
```
