## 표 파일 위치

- **엑셀 파일 전체 경로 예:** `d:\프로그램\Sqm\SQM_v590\docs\SQM_변수_테이블_문서.xlsx`  
  (프로젝트를 다른 드라이브/경로에 두었다면 그 경로의 `docs\SQM_변수_테이블_문서.xlsx`)

### 한 번에 보기 — 엑셀 한 파일 (시트 5개: 목차 + 데이터 4개)

| 파일명 | 설명 |
|--------|------|
| **SQM_변수_테이블_문서.xlsx** | **요청하신 데이터가 모두 들어 있습니다.** 목차 시트 + 아래 4개 시트. |

| 시트 이름 | 내용 |
|-----------|------|
| **목차** | 파일 위치, 시트 설명, 요청 사항 대비 (모두 포함 여부) |
| 매트릭스_공통헤더 | 13개 테이블 × 공통 헤더 31개 (O = 해당 테이블에 컬럼 있음) |
| 매트릭스_단일헤더 | 13개 테이블 × 1개 테이블 전용 헤더 |
| 변수_DB컬럼 | 변수명 / 의미 / 타입 / 사용처(테이블) — DB 컬럼 전부 |
| 변수_상수 | 변수명 / 의미 / 타입 / 사용처 — 비즈니스 상수 전부 |

엑셀 파일을 다시 만들려면: `python docs/build_sqm_docs_excel.py` 실행 (프로젝트 루트에서).

### CSV만 따로 쓰는 경우

| 파일명 | 설명 |
|--------|------|
| **SQM_테이ㅁㄴ블_헤더_매트릭스_공통헤더.csv** | 2개 이상 테이블에서 쓰는 헤더 31개 × 13개 테이블 (O = 해당 테이블에 컬럼 있음) |
| **SQM_테이블_헤더_매트릭스_단일헤더.csv** | 1개 테이블만 쓰는 헤더 × 13개 테이블 |

- **행:** 테이블 이름  
- **열:** 데이터 헤더(컬럼). **열 순서 = 해당 헤더를 쓰는 테이블 수가 많은 순** (많은 쪽이 왼쪽)  
- **셀:** O = 해당 테이블에 그 헤더 존재, 빈칸 = 없음  

CSV를 엑셀에서 열 때 **데이터 → 텍스트/CSV** 로 불러온 뒤 **UTF-8** 인코딩을 선택하면 한글이 정상 표시됩니다.
