## 1. 시작하기

### 1.1 프로그램 실행

```
1. sqm_inventory 폴더로 이동
2. gui_app.py 더블클릭 또는 명령창에서:
```

- **OS**: Windows 10/11

- **필수 패키지**: tkinter, openpyxl, pandas, PyMuPDF

## 3. 입고 처리

### 3.1 입고 화면

```
┌────────────────────────────────────────────────────┐
│  입고 처리                                         │
├────────────────────────────────────────────────────┤
│                                                    │
│  Step 1: D/O 파일 선택  [📁 파일 선택] [🔍 스캔]   │
│  Step 2: B/L 파일 선택  [📁 파일 선택] [🔍 스캔]   │
│  Step 3: P/L 파일 선택  [📁 파일 선택] [🔍 스캔]   │
│  Step 4: Invoice 선택   [📁 파일 선택] [🔍 스캔]   │
│                                                    │
│  ┌──────────────────────────────────────────────┐  │
│  │  스캔 결과 미리보기                          │  │
│  │                                              │  │
│  │  SAP NO: 2200001234                          │  │
│  │  B/L NO: BLMSCUGNP123                        │  │
│  │  제품: LITHIUM CARBONATE                     │  │
│  │                                              │  │
│  │  LOT 목록:                                   │  │
│  │  1120000001 | 5,000 kg | CONT001             │  │
│  │  1120000002 | 4,500 kg | CONT002             │  │
│  └──────────────────────────────────────────────┘  │
│                                                    │
│              [입고 처리]    [취소]                  │
└────────────────────────────────────────────────────┘
```

### 3.2 입고 절차

#### Step 1: 파일 선택
1. **D/O (Delivery Order)** 파일 선택 후 [스캔]
2. **B/L (Bill of Lading)** 파일 선택 후 [스캔]
3. **Packing List** 파일 선택 후 [스캔]
4. **Invoice** 파일 선택 후 [스캔] (선택사항)

#### Step 2: 데이터 확인
- 스캔 결과를 미리보기에서 확인
- SAP NO, B/L NO, LOT 정보 검토
- 필요시 수동 수정 가능

#### Step 3: 입고 실행
- [입고 처리] 버튼 클릭
- 성공 시: "3개 LOT 입고 완료" 메시지
- 실패 시: 오류 내용 표시

### 3.3 지원 파일 형식

| 문서 유형 | 지원 형식 |
|-----------|-----------|
| D/O | PDF, Excel (.xlsx) |
| B/L | PDF |
| Packing List | PDF, Excel (.xlsx) |
| Invoice | PDF, Excel (.xlsx) |

### 3.4 PDF 유형별 처리

- **텍스트 PDF**: 자동 파싱 (Gemini API 불필요)
- **이미지 PDF (스캔본)**: Gemini API 필요 (OCR)

## 4. 출고 처리

### 4.1 출고 화면

```
┌────────────────────────────────────────────────────┐
│  출고 처리                                         │
├────────────────────────────────────────────────────┤
│                                                    │
│  배분 파일: [📁 파일 선택]     [🔍 미리보기]       │
│                                                    │
│  ┌──────────────────────────────────────────────┐  │
│  │  출고 대상                                   │  │
│  │                                              │  │
│  │  LOT NO      | 수량(MT) | 고객      | 차량   │  │
│  │  1120000001  | 2.0      | CUST_A    | 서울01 │  │
│  │  1120000002  | 1.5      | CUST_B    | 서울02 │  │
│  │  1120000003  | 3.0      | CUST_C    | 광양01 │  │
│  │                                              │  │
│  │  합계: 6.5 MT                                │  │
│  └──────────────────────────────────────────────┘  │
│                                                    │
│              [출고 처리]    [취소]                  │
└────────────────────────────────────────────────────┘
```

### 4.2 출고 절차

1. **배분 파일 선택**
   - Excel 배분표 선택
   - 자동으로 LOT별 출고 수량 파싱

2. **출고 내용 확인**
   - LOT별 수량, 고객, 차량번호 확인
   - 재고 부족 항목은 빨간색으로 표시

3. **출고 실행**
   - [출고 처리] 클릭
   - 재고 자동 차감
   - 출고 이력 기록

### 4.3 배분표 양식

| 열 | 내용 | 필수 |
|----|------|------|
| LOT_NO | LOT 번호 | ✅ |
| OUTBOUND_QTY_KG | 출고 수량 (kg) | ✅ |
| CUSTOMER | 고객명 | - |
| TRUCK_NO | 차량번호 | - |
| DESTINATION | 목적지 | - |

### 4.4 LOT 상태 변화

| 상태 | 설명 |
|------|------|
| AVAILABLE | 가용 재고 |
| PARTIAL | 일부 출고됨 |
| DEPLETED | 전량 출고됨 (잔량 0) |

## 5. 재고 조회

### 5.1 재고 화면

```
┌────────────────────────────────────────────────────┐
│  재고 현황                   [새로고침] [내보내기] │
├────────────────────────────────────────────────────┤
│                                                    │
│  필터: [전체 ▼] [제품 ▼] [상태 ▼]    [🔍 검색]    │
│                                                    │
│  ┌──────────────────────────────────────────────┐  │
│  │ SAP NO     | LOT NO      | 제품   | 잔량(MT) │  │
│  ├──────────────────────────────────────────────┤  │
│  │ 2200001234 | 1120000001  | LC001  | 3.0      │  │
│  │ 2200001234 | 1120000002  | LC001  | 4.5      │  │
│  │ 2200001235 | 1120000010  | LC002  | 10.0     │  │
│  └──────────────────────────────────────────────┘  │
│                                                    │
│  요약: 총 10 LOT | 입고 50.0 MT | 잔량 45.5 MT    │
└────────────────────────────────────────────────────┘
```

### 5.2 필터 옵션

- **전체**: 모든 재고
- **가용재고**: 잔량 > 0인 항목만
- **소진재고**: 잔량 = 0인 항목만
- **제품별**: 특정 제품만

### 5.3 상세 조회

- LOT 더블클릭 시 상세 정보 표시:
  - 입고 정보 (날짜, 컨테이너, B/L)
  - 출고 이력
  - 톤백(Sub LOT) 목록

## 7. 설정

### 7.1 settings.ini

```ini
[Database]
path = sqm_inventory.db

[API]
GEMINI_API_KEY = your-api-key-here

[Options]
auto_backup = true
backup_interval = 7
```

### 7.2 Gemini API 설정

1. Google AI Studio에서 API 키 발급
2. settings.ini의 GEMINI_API_KEY에 입력
3. 또는 환경변수 설정:
   ```
   set GEMINI_API_KEY=your-key-here
   ```

## 8. 문제 해결

### 8.1 자주 묻는 질문

**Q: PDF 파싱이 안됩니다**
- A: 이미지 PDF는 Gemini API 키가 필요합니다

**Q: 중복 SAP NO 오류**
- A: 이미 등록된 SAP NO입니다. 다른 번호를 사용하세요

**Q: 재고가 음수로 표시됩니다**
- A: v2.9.41에서 음수 재고 방지 기능 추가됨

### 8.2 오류 메시지

| 오류 | 원인 | 해결 |
|------|------|------|
| LOT 번호가 비어있습니다 | LOT NO 미입력 | LOT 번호 확인 |
| 순중량이 0입니다 | 중량 0 | 중량 확인 |
| 이미 등록된 SAP NO | 중복 | 새 SAP NO 사용 |

### 8.3 데이터 백업

- 자동 백업: 7일마다 (설정 변경 가능)
- 수동 백업: [설정] → [백업 생성]
- 백업 위치: ./backups/

### 8.4 기술 지원

- **버전**: 2.9.41
- **담당**: 루비리 (남기동)
- **로그 위치**: ./logs/
