```javascript
// 기존 fetch → 타임아웃 + 재시도 래퍼로 교체
function sqmFetch(url, opts, timeoutMs, retries) {
    timeoutMs = timeoutMs || 15000;
    retries = retries === undefined ? 1 : retries;
    var ctrl = new AbortController();
    var timer = setTimeout(function() { ctrl.abort(); }, timeoutMs);
    return fetch(url, Object.assign({}, opts, { signal: ctrl.signal }))
        .then(function(r) { clearTimeout(timer); return r; })
        .catch(function(e) {
            clearTimeout(timer);
            if (retries > 0 && e.name === 'AbortError') {
                return sqmFetch(url, opts, timeoutMs, retries - 1);
            }
            throw e;
        });
}
```

**기대 효과:** Gemini/API 응답 없을 때 UI 무한 대기 방지, 자동 1회 재시도

**파일:** `backend/api/actions.py` 또는 신규 `backend/api/db_backup.py`

**작업 내용:**

- 보관 정책: 최근 30개만 유지 (자동 삭제)
- 백업 파일 크기가 50MB 이상이면 압축 (zlib)

```python
def auto_backup_before_write(db_path: str, operation: str) -> str:
    """중요 쓰기 작업 전 자동 백업. 백업 경로 반환."""
    backup_dir = Path(db_path).parent.parent / "backup"
    backup_dir.mkdir(exist_ok=True)
    ts = datetime.now().strftime("%Y%m%d_%H%M%S")
    dest = backup_dir / f"sqm_backup_{operation}_{ts}.db"
    shutil.copy2(db_path, dest)
    # 30개 초과 시 오래된 것 삭제
    backups = sorted(backup_dir.glob("sqm_backup_*.db"))
    for old in backups[:-30]:
        old.unlink()
    return str(dest)
```

**완료 기준:**
- [ ] 입고 처리 시 백업 파일 생성 확인

```python
def get_db_connection(db_path: str, retries: int = 3) -> sqlite3.Connection:
    """DB 연결 실패 시 최대 3회 재시도."""
    for attempt in range(retries):
        try:
            con = sqlite3.connect(db_path, timeout=10)
            con.execute("PRAGMA journal_mode=WAL")
            return con
        except sqlite3.OperationalError as e:
            if attempt == retries - 1:
                raise
            time.sleep(0.5 * (attempt + 1))
    raise RuntimeError("DB 연결 실패")
```

```javascript
function VirtualTable(container, data, rowHeight) {
    rowHeight = rowHeight || 36;
    var visibleCount = Math.ceil(container.clientHeight / rowHeight) + 5;
    
    function render(scrollTop) {
        var startIdx = Math.floor(scrollTop / rowHeight);
        var endIdx = Math.min(startIdx + visibleCount, data.length);
        // startIdx ~ endIdx 행만 렌더
        container.style.paddingTop = (startIdx * rowHeight) + 'px';
        container.style.paddingBottom = ((data.length - endIdx) * rowHeight) + 'px';
        renderRows(data.slice(startIdx, endIdx));
    }
    
    container.addEventListener('scroll', function() { render(this.scrollTop); });
    render(0);
}
```

### 3-2. AI 쿼리 결과 캐싱

```python
import hashlib, time

_query_cache: dict = {}  # hash → {result, expires}
CACHE_TTL = 30  # 30초

def _get_cached(question: str):
    key = hashlib.md5(question.encode()).hexdigest()
    entry = _query_cache.get(key)
    if entry and time.time() < entry['expires']:
        return entry['result']
    return None

def _set_cache(question: str, result):
    key = hashlib.md5(question.encode()).hexdigest()
    _query_cache[key] = {'result': result, 'expires': time.time() + CACHE_TTL}
    # 100개 초과 시 오래된 것 정리
    if len(_query_cache) > 100:
        expired = [k for k, v in _query_cache.items() if time.time() > v['expires']]
        for k in expired:
            del _query_cache[k]
```

**기대 효과:** 같은 질문 반복 시 Gemini 호출 없이 즉시 응답

**파일:** `frontend/detached/ai_chat.html`

**작업 내용:**
- 질문 입력창 옆 ⭐ 버튼 → 현재 질문 즐겨찾기 저장
- 저장 위치: localStorage `sqm_fav_queries`
- 최대 10개, 채팅 상단에 버튼으로 표시

```javascript
function saveFavorite(query) {
    var favs = JSON.parse(localStorage.getItem('sqm_fav_queries') || '[]');
    if (!favs.includes(query)) {
        favs.unshift(query);
        favs = favs.slice(0, 10);  // 최대 10개
        localStorage.setItem('sqm_fav_queries', JSON.stringify(favs));
        renderFavorites();
    }
}
```

**완료 기준:**
- [ ] ⭐ 클릭 → 즐겨찾기 저장
- [ ] 저장된 질문 버튼으로 표시
