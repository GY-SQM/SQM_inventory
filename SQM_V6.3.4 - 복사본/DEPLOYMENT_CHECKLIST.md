# ✅ SQM Inventory v3.2 배포 테스트 체크리스트

> 이 체크리스트로 배포 전 테스트를 진행하세요.

---

## 🖥️ 테스트 환경 준비

### 방법 1: Windows Sandbox (추천)
```
1. Windows 설정 > 앱 > 선택적 기능 > Windows Sandbox 활성화
2. 재부팅 후 시작 메뉴에서 "Windows Sandbox" 실행
3. EXE 파일을 Sandbox에 드래그앤드롭
```

### 방법 2: 다른 PC
```
- Python이 설치되지 않은 Windows PC
- 동료 PC 또는 가족 PC
```

### 방법 3: 가상 머신
```
- VMware 또는 VirtualBox
- 순수 Windows 10/11 설치
```

## 📋 테스트 체크리스트

### 1단계: EXE 빌드 (개발 PC)

```
[ ] Python 3.10+ 설치 확인
[ ] pip install pyinstaller 완료
[ ] sqm_v3.2 폴더로 이동
[ ] build_exe.bat 실행
[ ] dist/SQM_Inventory_v3.2.exe 생성 확인
[ ] 파일 크기 50~150MB 범위 내
```

**빌드 오류 시:**
- 오류 메시지 복사
- Claude에게 전달하여 해결

---

### 2단계: 기본 실행 테스트 (클린 환경)

```
[ ] EXE 파일 복사 (USB, 공유폴더, 드래그앤드롭)
[ ] EXE 더블클릭
[ ] Windows SmartScreen 경고 시 "추가 정보" → "실행"
[ ] 5초 이내 메인 창 표시
[ ] 오류 대화상자 없음
[ ] "SQM 재고관리 v3.2" 제목 표시
```

**결과:**
- [ ] 통과
- [ ] 실패 → 오류 메시지: _________________

### 3단계: UI 테스트

```
[ ] 메뉴바 정상 표시
```
