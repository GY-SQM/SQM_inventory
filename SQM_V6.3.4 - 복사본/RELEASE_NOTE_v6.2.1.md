# RELEASE NOTE — v6.2.1

배포일: 2026-02-27  
버전: `6.2.1`

## 핵심 변경

- D/O 후속 연결 안정성 강화
  - `con_return`, `free_time_date`, `warehouse`까지 후속 업데이트 반영
  - BL 매칭: 정규화 + exact 우선, 필요 시 BL+Container 보조 매칭
  - 적용 전 Diff 미리보기(기존값/신규값) 확인
  - 적용 전 DB 백업 스냅샷 자동 생성
  - 적용 후 검증 리포트 자동 출력(업데이트/스킵/불일치)

- 원스톱 입고 미리보기 UX 개선
  - 파싱 직후 Packing List 원본 순서 유지
  - 컬럼 헤더 오름/내림 정렬(▲/▼)
  - 콤보 필터 검색 바 추가(SAP/BL/CONTAINER/PRODUCT/STATUS)
  - `원본 초기화` 버튼 추가(파싱 직후 상태로 복원)
  - `DB 업로드 시 현재 정렬/필터 순서 적용` 토글 추가

- 파싱 로그/동작 품질 개선
  - `ship_date` 추출을 신규 3단계 엔진으로 교체(BL 번호 로직은 유지)
  - 날짜 미추출 로그 레벨 정리(ERROR → WARNING)

- 테스트 DB 초기화 안전성 강화
  - 삭제/재생성 경로 단일화
  - `.db`, `-wal`, `-shm`, `-journal`, `.checksum` 동시 정리
  - 재생성 후 무결성 및 0건 검증
  - 실패 시 `sqm_before_reset_*.db` 원클릭 롤백 복원

## 영향 범위

- 원스톱 입고 미리보기/업로드 플로우
- D/O 후속 연결 다이얼로그
- 테스트 DB 초기화 메뉴
- B/L Ship Date 추출 보조 로직

## 운영 메모

- 개발자 모드 OFF에서는 `테스트 DB 초기화` 메뉴가 숨김 처리됩니다.
- DB 초기화는 복구 가능한 백업을 남기지만, 운영 DB에서는 신중히 사용하세요.
