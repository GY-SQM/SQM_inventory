## 🚨 즉시 롤백 트리거 (P0)

다음 중 하나라도 발생 시 **즉시** `python tools\rollback.py --to-backup latest`:

1. 데이터 손실 또는 증발
2. 출고/입고 기록이 저장 안 됨
3. ALERTS 가 사라지고 안 뜸
4. 프로그램 시작 5초 내 크래시
5. DB 무결성 오류 (정합성 검사 실패가 거짓 양성으로 폭주)
